# LeetCode 象到达目标格子的最少移动步数 题解

## 1. 题目概述

- **标题 / 题号**：象到达目标格子的最少移动步数（#4034，medium）
- **链接**：https://leetcode.cn/problems/minimum-bishop-moves-to-reach-target/
- **来源**：LeetCode 第 190 场双周赛 Q1
- **难度**：中等
- **标签**：数学、棋盘、找规律

**题意**：$8 \times 8$ 棋盘（行列下标从 $1$ 开始），一枚象从 `source` 出发，每步可沿**单个对角线方向**移动任意格数（不能出界）。求**恰好**到达 `target` 的最少步数，永远无法到达则返回 $-1$。

**约束**：

- `source.length == target.length == 2`
- $1 \le sr, sc, tr, tc \le 8$
- `source != target`

## 2. 示例

**示例 1**

```text
输入：source = [8,1], target = [1,8]
输出：1
解释：从 (8,1) 沿主对角线方向一步直达 (1,8)，两格同行差与列差均为 7。
```

**示例 2**

```text
输入：source = [4,2], target = [1,3]
输出：2
解释：(4,2) → (3,1) → (1,3)，两步对角线移动；二者不在同一对角线上但同色。
```

**示例 3**

```text
输入：source = [1,1], target = [3,4]
输出：-1
解释：(1,1) 与 (3,4) 异色，象无论走多少步都在同色格上，永远无法到达。
```

## 3. 解题思路

### 3.1 暴力思路

从 `source` 出发对 $64$ 个格子做 BFS，每个格子向 $4$ 个对角线方向连边，复杂度 $O(64^2)$。对本题数据完全可以接受，但题目本质是数学规律题，存在 $O(1)$ 判定。

### 3.2 核心观察：颜色不变量

![象的最少步数：颜色不变量与三类判定](images/bw190_q1_bishop_color.svg)

国际象棋棋盘黑白染色：格子 $(r, c)$ 的颜色由 $r + c$ 的**奇偶性**决定。象一步移动中行、列变化量为 $(\pm d, \pm d)$，于是 $r + c$ 的变化量只能是 $0$ 或 $\pm 2d$——**奇偶性永远不变**。因此：

- **异色**：永远不可达，返回 $-1$；
- **同一对角线**（$|\Delta r| = |\Delta c|$）：一步直达；
- **同色但不同对角线**：两步可达（下面证明）。

由于 `source != target`，答案只可能是 $1$、$2$ 或 $-1$。

### 3.3 两步的中转点构造

![两步路径：u/v 构造中转点 M](images/bw190_q1_two_moves.svg)

设 $S=(r_1,c_1)$、$T=(r_2,c_2)$，$\Delta r = r_2 - r_1$、$\Delta c = c_2 - c_1$。同色 $\iff \Delta r \equiv \Delta c \pmod 2$，于是

$$u = \frac{\Delta r + \Delta c}{2}, \qquad v = \frac{\Delta r - \Delta c}{2}$$

都是整数。取两个候选中转点：

- $M = S + (u, u)$：$S \to M$ 沿主对角线方向，$M \to T$ 的位移为 $(v, -v)$，沿副对角线方向；
- $M' = S + (v, -v)$：$S \to M'$ 沿副对角线方向，$M' \to T$ 的位移为 $(u, u)$，沿主对角线方向。

可以证明（见 §5）二者至少有一个落在棋盘内，且都与 $S$、$T$ 不重合。

### 3.4 判定流程

```text
1. 若 source == target          → 0   （题面保证不会出现，防御性返回）
2. 若 |Δr| == |Δc|              → 1   （同一对角线，一步直达）
3. 若 (sr+sc) 与 (tr+tc) 同奇偶  → 2   （同色，经中转点两步）
4. 否则                          → -1  （异色，不可达）
```

注意判断顺序：同一对角线的两格必然同色，必须先判对角线再判颜色，否则会把答案 $1$ 误报成 $2$。

## 4. 算法细节

1. **颜色判定**：用 $(sr + sc + tr + tc)$ 的奇偶性即可——它为偶当且仅当 $r_1+c_1$ 与 $r_2+c_2$ 同奇偶。坐标均为正数，C++ 取模无负数陷阱。
2. **对角线判定**：$|sr - tr| == |sc - tc|$，注意用绝对值。
3. **无需显式构造中转点**：判定流程是纯 $O(1)$ 的四行比较；中转点构造仅用于证明「同色 ⟹ 两步」这一事实。
4. **推广性**：该结论对任意 $n \times n$（$n \ge 2$）棋盘都成立，$8 \times 8$ 只是具体规模。

## 5. 正确性证明

**引理 1（颜色不变量）**：象每步使 $(r, c)$ 变为 $(r \pm d, c \pm d)$，$r + c$ 的变化量为 $0$ 或 $\pm 2d$，故 $r+c$ 的奇偶性不变。因此起点与终点异色时不可达。∎

**引理 2**：一步可达 $\iff |\Delta r| = |\Delta c|$（沿某对角线方向一步可到该线上任意格）。∎

**定理**：同色且不同对角线的两格，恰好两步可达。

**证明**：同色保证 $u, v \in \mathbb{Z}$；不同对角线保证 $u \ne 0$ 且 $v \ne 0$（$u=0 \iff \Delta r = -\Delta c$ 即同副对角线，$v=0 \iff \Delta r = \Delta c$ 即同主对角线），于是 $M$、$M'$ 方案中两段移动都非零，且 $M, M' \notin \{S, T\}$。

再证至少一个中转点在棋盘内。由行翻转、列翻转与主副对角线互换（转置）的对称性，不妨设 $0 \le \Delta c < \Delta r$，则 $0 < v \le u \le \Delta r$。两个候选点的**行**坐标满足 $r_1 + v \le r_1 + u \le r_1 + \Delta r = r_2 \le 8$，必然合法；若 $M$、$M'$ 都越界，只能是**列**越界：

$$c_1 + u > 8 \quad \text{且} \quad c_1 - v < 1 \;\Rightarrow\; v \ge c_1 \ge 9 - u \;\Rightarrow\; u + v \ge 9$$

但 $u + v = \Delta r \le 7$（棋盘内两格行差至多 $7$），矛盾。故 $M$ 或 $M'$ 在棋盘内，两步可达；又由引理 2 知一步不可达，故恰好两步。∎

**推论**：答案 = 同格 $0$ / 同对角线 $1$ / 同色 $2$ / 异色 $-1$。∎

## 6. 复杂度分析

- **时间**：$O(1)$，仅常数次比较与加减。
- **空间**：$O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int minBishopMoves(vector<int>& source, vector<int>& target) {
        int sr = source[0], sc = source[1];
        int tr = target[0], tc = target[1];
        if (sr == tr && sc == tc) return 0;
        if (abs(sr - tr) == abs(sc - tc)) return 1;
        if ((sr + sc + tr + tc) % 2 == 0) return 2;
        return -1;
    }
};
```

### Python

```python
class Solution:
    def minBishopMoves(self, source: list[int], target: list[int]) -> int:
        sr, sc = source
        tr, tc = target
        if (sr, sc) == (tr, tc):
            return 0
        if abs(sr - tr) == abs(sc - tc):
            return 1
        if (sr + sc + tr + tc) % 2 == 0:
            return 2
        return -1
```

## 8. 边界情况与易错点

1. **判断顺序**：必须先判「同一对角线」再判「同色」，否则 $1$ 步可达的格子会被误判为 $2$ 步。
2. **`source == target`**：题面保证不出现，但代码防御性返回 $0$ 更稳妥。
3. **异色判断**：$(r+c)$ 与 $(r-c)$ 的奇偶性都可用；本题坐标恒正，C++ 中 `% 2` 无负数问题。
4. **相邻格**：如 $(1,1) \to (1,2)$，$\Delta r = 0$、$\Delta c = 1$，异色，正确返回 $-1$，别误以为「很近就能到」。
5. **方向不限**：每步可沿对角线走任意格，不能按「一次走一格」去数步数。
