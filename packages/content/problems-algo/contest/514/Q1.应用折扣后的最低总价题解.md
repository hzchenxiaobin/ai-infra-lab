# LeetCode 应用折扣后的最低总价 题解

## 1. 题目概述

- **标题 / 题号**：应用折扣后的最低总价（#4014，medium）
- **链接**：https://leetcode.cn/problems/minimum-total-price-after-applying-discounts/
- **来源**：LeetCode 第 514 场周赛 Q1
- **难度**：中等
- **标签**：贪心、排序、重排不等式

**题意**：给定商品价格数组 `prices` 和折扣百分比数组 `discounts`。每个折扣最多用于一件商品、每件商品最多用一个折扣（也可不用）。折扣 $d\%$ 作用于价格 $p$ 后变 $p(100-d)/100$，**不四舍五入**。求所有商品最终价格之和的最小值（误差 $10^{-5}$ 内即接受）。

**约束**：

- $1 \le \text{prices.length}, \text{discounts.length} \le 10^5$
- $1 \le \text{prices}[i] \le 10^5$
- $1 \le \text{discounts}[j] \le 100$

## 2. 示例

**示例 1**

```text
输入：prices = [10,30,21], discounts = [50,60]
输出：32.50000
解释：60% 折扣用于 30 → 12；50% 折扣用于 21 → 10.5；10 不打折。
      总价 12 + 10.5 + 10 = 32.5。
```

**示例 2**

```text
输入：prices = [100,70], discounts = [10,40,50]
输出：92.00000
解释：50% 用于 100 → 50；40% 用于 70 → 42。总价 92。
```

**示例 3**

```text
输入：prices = [7,3,9], discounts = [100,100]
输出：3.00000
解释：两个 100% 折扣分别用于 9 和 7 → 均为 0；3 不打折。
```

## 3. 解题思路

### 3.1 暴力思路

枚举折扣与商品的匹配方式（$n$ 件商品、$m$ 个折扣的匹配是排列级组合），$O(n!)$ 显然不可行。需找到「最优匹配」的结构。

### 3.2 核心观察：重排不等式 + 贪心配对

![贪心配对：大折扣配大价格（重排不等式）](images/discount_greedy_pairing.svg)

两个关键事实：

1. **折扣一定用掉**：$d \ge 1$，故 $p(100-d)/100 < p$，使用任意折扣都使价格严格下降。因此能配尽配，配对数 $k = \min(n, m)$。
2. **同序配对最优**：总减免 $= \sum p_i \cdot d_{\sigma(i)} / 100$。要使其最大，由**重排不等式**，两个序列**同序排序**（都降序）时乘积和最大。即把最大价格配最大折扣、次大配次大……

### 3.3 算法流程

1. 将 `prices` 升序排序后翻转（或直接降序），记为 $p\downarrow$。
2. 将 `discounts` 降序排序，记为 $d\downarrow$。
3. 设 $k = \min(n, m)$。减免 $R = \sum_{i=0}^{k-1} p\downarrow_i \cdot d\downarrow_i / 100$。
4. 原价之和 $S = \sum \text{prices}[i]$。
5. 答案 $= S - R$。

### 3.4 示例演算

![示例演算：prices=[10,30,21], discounts=[50,60]](images/discount_walkthrough.svg)

`prices=[10,30,21]`、`discounts=[50,60]`：$p\downarrow = [30,21,10]$，$d\downarrow = [60,50]$，$k=2$。减免 $= 30\cdot60/100 + 21\cdot50/100 = 18 + 10.5 = 28.5$。$S = 61$。答案 $= 61 - 28.5 = 32.5$ ✓。

> 💡 反向错配 $(30,50),(21,60)$ 给减免 $15 + 12.6 = 27.6 < 28.5$，验证同序最优。

## 4. 算法细节

1. **为何重排不等式适用**：重排不等式断言，对两组数 $a_1 \ge \cdots \ge a_n$、$b_1 \ge \cdots \ge b_n$ 与任一排列 $\sigma$，有 $\sum a_i b_i \ge \sum a_i b_{\sigma(i)}$。本题 $a_i = p_i$、$b_i = d_i$，同序（都降序）使 $\sum p_i d_i$ 最大，即减免最大、总价最小。
2. **配对数取 $\min(n,m)$**：折扣比商品多时多余的折扣丢弃（无商品可配）；商品比折扣多时多余商品原价计入。降序后取前 $k$ 个配对，剩余自然不配。
3. **精度处理**：题目要求 $10^{-5}$ 内即可，`double` 足够。最终价格不做四舍五入，直接累加浮点。为避免整数除法丢精度，C++ 中先乘后除：`p * d / 100.0`。
4. **求和规模**：$\sum p \le 10^5 \cdot 10^5 = 10^{10}$，C++ `long long` 存原价和；最终除 $100$ 转浮点。

## 5. 正确性证明

**引理 1**（折扣必用）：在最优方案中，使用的折扣数 $= \min(n, m)$。

**证明**：若存在某折扣 $d \ge 1$ 未使用且存在某商品未配折扣，则把该折扣用于该商品，价格减少 $p\cdot d/100 > 0$，总价严格下降，与最优矛盾。故能配尽配。$\square$

**引理 2**（同序最优）：在所有大小为 $k$ 的匹配中，$\sum p_i d_{\sigma(i)}$ 在「$p$ 降序、$d$ 降序、按下标对齐」时取最大值。

**证明**：即重排不等式。设 $p_1 \ge p_2$、$d_1 \ge d_2$，则 $p_1 d_1 + p_2 d_2 - (p_1 d_2 + p_2 d_1) = (p_1 - p_2)(d_1 - d_2) \ge 0$，即同序不劣于逆序。任意逆序对经交换不使和下降，反复交换至完全同序即得最大。$\square$

**定理**：算法返回最小总价。

**证明**：总价 $= S - R$，$S$ 固定，最小化总价等价于最大化减免 $R$。由引理 1，最优配对数为 $k = \min(n,m)$；由引理 2，同序配对使 $R$ 最大。算法恰如此配对并返回 $S - R$，故为最优。$\square$

## 6. 复杂度分析

- **时间复杂度**：$O(n \log n + m \log m)$。两次排序为主，求和为线性。
- **空间复杂度**：$O(n + m)$（排序副本）。若原地排序可 $O(1)$ 额外。

$n, m \le 10^5$，约 $10^5 \log 10^5 \approx 1.7 \times 10^6$ 次比较，C++ < 20 ms，Python < 0.1 s。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    double minimumTotalPrice(vector<int>& prices, vector<int>& discounts) {
        sort(prices.begin(), prices.end(), greater<int>());
        sort(discounts.begin(), discounts.end(), greater<int>());
        int k = min(prices.size(), discounts.size());
        double reduction = 0.0;
        for (int i = 0; i < k; ++i)
            reduction += (double)prices[i] * discounts[i] / 100.0;
        long long total = 0;
        for (int p : prices) total += p;
        return (double)total - reduction;
    }
};
```

### Python

```python
class Solution:
    def minimumTotalPrice(self, prices: list[int], discounts: list[int]) -> float:
        prices.sort(reverse=True)
        discounts.sort(reverse=True)
        k = min(len(prices), len(discounts))
        reduction = sum(prices[i] * discounts[i] / 100 for i in range(k))
        total = sum(prices)
        return total - reduction
```

## 8. 边界情况与易错点

1. **整数除法丢精度**：C++ 中 `prices[i] * discounts[i] / 100` 是整数除法（会截断），必须 `/ 100.0` 或先转 `double`。Python 的 `/` 天然浮点。
2. **`discounts` 比 `prices` 多**：多余的折扣丢弃，`k = min(n,m)` 自动处理，勿越界。
3. **`prices` 比 `discounts` 多**：多余商品原价计入，求 `total` 时用全部 `prices`（非仅前 $k$ 个）。
4. **`d = 100`**：价格归零，公式 $p \cdot 0 / 100 = 0$ 正确。
5. **求和溢出**：$\sum p$ 可达 $10^{10}$，超 32 位 `int`，C++ 用 `long long`。
6. **不四舍五入**：题目明确最终价格不四舍五入，直接累加 `double` 即可，末尾无需格式化取整。
