# LeetCode 电梯请求 I 题解

## 1. 题目概述

- **标题 / 题号**：电梯请求 I（#4020，easy）
- **链接**：https://leetcode.cn/problems/elevator-requests-i/
- **来源**：LeetCode 第 189 场双周赛 Q1
- **难度**：简单
- **标签**：模拟、数组

**题意**：电梯初始在 $0$ 层，按给定顺序处理 `requests` 中的楼层请求。每秒移动一层，已在目标层则无需移动。返回处理所有请求的总时间。

**约束**：

- $1 \le n \le 100$
- $1 \le \text{requests.length} \le 100$
- $0 \le \text{requests[i]} \le n - 1$

## 2. 示例

**示例 1**

```text
输入：n = 5, requests = [2,1,4,3]
输出：7
解释：0→2(2s)→1(1s)→4(3s)→3(1s)，总 7 秒。
```

**示例 2**

```text
输入：n = 3, requests = [2,0,0]
输出：4
解释：0→2(2s)→0(2s)→0(0s)，总 4 秒。
```

## 3. 解题思路

### 3.1 核心观察：累加楼层差

![电梯请求 I：依次处理，累加楼层差](images/bw189_q1_elevator_sim.svg)

电梯按顺序处理请求，每步耗时为当前楼层与目标楼层之差的绝对值。总时间即为所有相邻移动（含起点 $0$）的距离之和：

$$\text{ans} = \sum_{i=0}^{m-1} |\text{requests}[i] - \text{prev}|, \quad \text{prev 初始为 } 0$$

### 3.2 算法流程

1. `prev = 0`, `ans = 0`。
2. 遍历 `requests`：`ans += abs(req - prev)`, `prev = req`。
3. 返回 `ans`。

## 4. 算法细节

- `n` 仅用于约束楼层范围，算法本身不依赖 `n`。
- 已在目标层时 `abs(req - prev) == 0`，自然处理。

## 5. 正确性证明

**定理**：总时间 $= \sum |\text{requests}[i] - \text{prev}_i|$。

**证明**：电梯每秒移动一层，从 `prev` 到 `req` 的耗时恰为 $|\text{req} - \text{prev}|$。处理完立即向下一请求移动，无等待。各段独立累加即为总时间。$\square$

## 6. 复杂度分析

- **时间复杂度**：$O(m)$，一次遍历。
- **空间复杂度**：$O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int elevatorRequests(int n, vector<int>& requests) {
        int prev = 0, ans = 0;
        for (int r : requests) {
            ans += abs(r - prev);
            prev = r;
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def elevatorRequests(self, n: int, requests: list[int]) -> int:
        prev = ans = 0
        for r in requests:
            ans += abs(r - prev)
            prev = r
        return ans
```

## 8. 边界情况与易错点

1. **起点为 0**：`prev` 初始为 $0$，不是 `requests[0]`。
2. **连续相同楼层**：如 `requests = [0, 0]`，第二步耗时 $0$。
3. **`n` 不参与计算**：仅约束输入合法性，无需用于边界判断。
