# LeetCode 统计有效前缀数目 题解

## 1. 题目概述

- **标题 / 题号**：统计有效前缀数目（#4006，easy）
- **链接**：https://leetcode.cn/problems/count-valid-prefixes/
- **来源**：LeetCode 第 188 场双周赛 Q1
- **难度**：简单
- **标签**：字符串、前缀统计、贪心

**题意**：给定二进制字符串 `s`。如果 `s` 的某个前缀的字符可以重新排列成交替字符串（没有两个相邻字符相等），则该前缀有效。返回有效前缀的数量。

**约束**：

- $1 \le \text{s.length} \le 100$
- `s` 仅由 `'0'` 和 `'1'` 组成

## 2. 示例

**示例 1**

```text
输入：s = "00101"
输出：3
解释：有效前缀为 "0"、"001"、"00101"。
"00" 的 c0=2,c1=0,|2-0|=2 > 1，无法重排成交替串。
"0010" 的 c0=3,c1=1,|3-1|=2 > 1，同样无效。
```

**示例 2**

```text
输入：s = "101"
输出：3
解释：所有前缀都已是交替字符串，全部有效。
```

## 3. 解题思路

### 3.1 暴力思路

枚举每个前缀，排序后检查是否交替。$O(n^2 \log n)$，$n=100$ 虽能过但完全没有必要。

### 3.2 核心观察：交替二进制串的计数条件

![有效前缀：|count0 - count1| <= 1 即可重排为交替串](images/bw188_q1_valid_prefix.svg)

**关键性质**：长度为 $L$ 的二进制串能重排成交替串，当且仅当 $0$ 和 $1$ 的数量之差不超过 $1$：

$$|c_0 - c_1| \le 1$$

- $L$ 为偶数时，交替串中 $0$ 和 $1$ 各占一半，要求 $c_0 = c_1$。
- $L$ 为奇数时，交替串中两种字符相差 $1$，要求 $|c_0 - c_1| = 1$。
- 长度为 $1$ 时 $|c_0 - c_1| = 1 \le 1$，单字符总是有效。

合并两种情况即 $|c_0 - c_1| \le 1$。

### 3.3 算法流程

1. 初始化 $c_0 = 0, c_1 = 0, \text{ans} = 0$。
2. 逐字符遍历 `s`，维护前缀中 $0$ 和 $1$ 的计数。
3. 每加入一个字符后，若 $|c_0 - c_1| \le 1$，则 `ans += 1`。
4. 返回 `ans`。

## 4. 算法细节

- 只需一次遍历，维护两个计数器（或一个差值变量 `diff = c0 - c1`）。
- $|c_0 - c_1| \le 1$ 等价于 $|\text{diff}| \le 1$，即 `diff` 取值在 $\{-1, 0, 1\}$ 中。

## 5. 正确性证明

**引理**：长度为 $L$ 的二进制串可重排成交替串，当且仅当 $|c_0 - c_1| \le 1$。

**证明**：

（必要性）交替二进制串中相邻字符不同，因此 $0$ 和 $1$ 交替出现。若以 $0$ 开头，则奇数位为 $0$、偶数位为 $1$，$c_0 = \lceil L/2 \rceil$，$c_1 = \lfloor L/2 \rfloor$；若以 $1$ 开头则反之。两种情况下 $|c_0 - c_1| \le 1$。

（充分性）若 $|c_0 - c_1| \le 1$，设 $c_0 \ge c_1$（否则对称）。将较多的 $0$ 放在奇数位、较少的 $1$ 放在偶数位，恰好填满 $L$ 个位置且相邻不同。$\square$

**定理**：逐前缀判断 $|c_0 - c_1| \le 1$ 并计数，得到正确答案。

**证明**：由引理，每个前缀的有效性等价于 $|c_0 - c_1| \le 1$。前缀计数可增量维护（每加入一个字符更新 $c_0$ 或 $c_1$），$O(n)$ 遍历覆盖所有前缀。$\square$

## 6. 复杂度分析

- **时间复杂度**：$O(n)$，一次遍历，每步 $O(1)$。
- **空间复杂度**：$O(1)$，仅两个计数器。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int countValidPrefixes(string s) {
        int c0 = 0, c1 = 0, ans = 0;
        for (char ch : s) {
            if (ch == '0') ++c0; else ++c1;
            if (abs(c0 - c1) <= 1) ++ans;
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def countValidPrefixes(self, s: str) -> int:
        c0 = c1 = ans = 0
        for ch in s:
            if ch == '0':
                c0 += 1
            else:
                c1 += 1
            if abs(c0 - c1) <= 1:
                ans += 1
        return ans
```

## 8. 边界情况与易错点

1. **单字符**：$L=1$ 时 $|c_0 - c_1| = 1 \le 1$，总是有效。
2. **全相同字符**：如 `"0000"`，只有 $L=1$ 时有效（$|1-0|=1$），$L \ge 2$ 时 $|c_0 - c_1| \ge 2$ 无效。
3. **差值溢出**：$n \le 100$，`abs(c0 - c1)` 不超过 100，`int` 足够。
4. **用差值变量优化**：可只维护 `diff = c0 - c1`，`ch=='0'` 时 `diff++` 否则 `diff--`，判断 `abs(diff) <= 1`。
