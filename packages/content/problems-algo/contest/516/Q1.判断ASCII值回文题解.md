# LeetCode 判断 ASCII 值回文 题解

## 1. 题目概述

- **标题 / 题号**：判断 ASCII 值回文（#4381，easy）
- **链接**：https://leetcode.cn/problems/check-ascii-palindromic/
- **来源**：LeetCode 第 516 场周赛 Q1
- **难度**：简单
- **标签**：字符串、位运算、模拟

**题意**：给定小写字母字符串 `s`，把每个字符替换为其 ASCII 值的 **8 位二进制**表示（含前导零），按原顺序拼接成一个二进制串。判断该二进制串是否为回文。

**约束**：

- `1 <= s.length <= 100`
- `s` 仅由小写英文字母组成

## 2. 示例

**示例 1**

```text
输入：s = "ff"
输出：true
解释：f 的 ASCII = 102 = 01100110，拼接得 0110011001100110，是回文。
```

**示例 2**

```text
输入：s = "leet"
输出：false
解释：l,e,e,t 的 8 位二进制分别为 01101100、01100101、01100101、01110100，
      拼接得 01101100011001010110010101110100，不是回文。
```

**示例 3**

```text
输入：s = "f"
输出：true
解释：f 的 ASCII = 102 = 01100110，该 8 位串本身即为回文（首尾逐位相等）。
```

## 3. 解题思路

### 3.1 暴力思路

直接按题意模拟：对每个字符取 ASCII 值，转 8 位二进制（补前导零），拼接成完整二进制串，再判断是否回文。`s.length <= 100`，拼接串最长 `800` 位，模拟完全可行。

### 3.2 核心观察：模拟 + 双指针判回文

![字符 → ASCII → 8 位二进制 → 拼接](images/ascii_palindrome_concept.svg)

**转换公式**：

```text
binary(c) = c 的 ASCII 值的低 8 位，补前导零到 8 位
```

小写字母 ASCII 在 `97~122`，均落在 8 位无符号范围内，二进制以 `0110` / `0111` 开头。

**判回文**：拼接出串 `t` 后，直接 `t == t[::-1]`，或双指针首尾比较。

### 3.3 示例演算

![示例演算：s="ff" 首尾配对判定](images/ascii_palindrome_example.svg)

`s = "ff"`：两段 `01100110` 拼成 `0110011001100110`，首尾双指针逐位比较全部相等 → `true`。

## 4. 算法细节

1. **取 ASCII 值**：C++ 用 `int(c)`；Python 用 `ord(c)`。
2. **转 8 位二进制**：
   - C++：`bitset<8>(c).to_string()`，或手动从高位到低位逐位取 `(x >> i) & 1`。
   - Python：`bin(ord(c))[2:].zfill(8)`，`zfill(8)` 保证补足前导零。
3. **拼接**：将每个字符的 8 位串依次累加到一个字符串 `t`。
4. **判回文**：`t == reverse(t)`。也可双指针 `i`、`j` 从两端向中间比较，遇不等返回 `false`。

## 5. 正确性证明

**引理 1**：`binary(c)` 是 `c` 的 ASCII 值的准确 8 位二进制表示。

**证明**：`bitset<8>` / `zfill(8)` 将数值按二进制写出并补齐到 8 位，低位不足处补 `0`，与定义一致。小写字母 ASCII ∈ [97,122] ⊂ [0,255]，8 位可完整表示。∎

**定理**：算法返回 `true` 当且仅当拼接后的二进制串是回文。

**证明**：由引理 1，`t` 即题目定义的二进制串。回文的定义是 `t[i] == t[L-1-i]` 对所有 `i` 成立，等价于 `t == reverse(t)`。算法据此判定，故正确。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$，其中 $n = s.\text{length}$。每个字符转 8 位二进制为 $O(1)$，拼接与判回文共 $O(8n) = O(n)$。
- **空间复杂度**：$O(n)$。存储拼接串，最长 $800$ 个字符。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    bool isPalindromic(string s) {
        string t;
        for (char c : s) {
            bitset<8> b((unsigned char)c);
            t += b.to_string();
        }
        int i = 0, j = (int)t.size() - 1;
        while (i < j) {
            if (t[i] != t[j]) return false;
            i++; j--;
        }
        return true;
    }
};
```

### Python

```python
class Solution:
    def isPalindromic(self, s: str) -> bool:
        t = "".join(bin(ord(c))[2:].zfill(8) for c in s)
        return t == t[::-1]
```

## 8. 边界情况与易错点

1. **前导零不能省**：`f` 的 ASCII = 102，二进制 `1100110` 只有 7 位，必须补成 `01100110`。若用 `bin(x)[2:]` 不补零，位数错位会导致错误。
2. **单字符并非必回文**：单字符时拼接串就是其 8 位二进制，需该串本身回文才返回 `true`。例如 `f` = `01100110` 是回文 → `true`；而 `a` = `01100001` 首位 `0` 末位 `1` 不等 → `false`。不能默认单字符必回文。
3. **字符顺序**：拼接必须保持 `s` 中字符原顺序，不可排序或反转。
4. **unsigned char 转换**：C++ 中 `char` 可能带符号，转 `bitset<8>` 前应先 `(unsigned char)c`，避免负值导致高位全 1。
