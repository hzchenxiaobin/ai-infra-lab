# LeetCode 恰好有 K 对相等相邻字符的循环移位数量 题解

## 1. 题目概述

- **标题 / 题号**：恰好有 K 对相等相邻字符的循环移位数量(#4043,Easy)
- **链接**:https://leetcode.cn/problems/count-rotations-with-exactly-k-equal-adjacent-pairs/
- **来源**:LeetCode 第 518 场周赛 Q1
- **难度**:简单
- **标签**:字符串、枚举、计数

**题意**:给定长度为 $n$ 的字符串 $s$ 与整数 $k$。一次**循环移位**指选一个长度在 $0$ 到 $n-1$ 之间的前缀,把它整体移到末尾(保持相对顺序)。对一个移位后的字符串,其**得分**定义为满足 $0 \le i < n-1$ 且位置 $i$ 与 $i+1$ 字符相同的下标 $i$ 的数量。求得分**恰好等于** $k$ 的移位有多少个。

**约束**:

- $2 \le n \le 100$
- $s$ 仅含小写英文字母
- $0 \le k \le n - 1$

## 2. 示例

**示例 1**

```text
输入:s = "aab", k = 1
输出:2
解释:三种移位 "aab"、"aba"、"baa" 的得分依次为 1、0、1,其中 2 个等于 k。
```

**示例 2**

```text
输入:s = "abca", k = 0
输出:1
解释:四种移位 "abca"、"bcaa"、"caab"、"aabc" 的得分依次为 0、1、1、1,只有 1 个等于 k。
```

## 3. 解题思路

### 3.1 暴力思路

枚举全部 $n$ 个移位,对每个移位**重新拼出字符串**并逐对统计相邻相等对数,单次 $O(n)$,总复杂度 $O(n^2)$。

由于 $n \le 100$,$O(n^2) = 10^4$ 完全可以通过。但每个移位的得分其实可以 $O(1)$ 算出,无需真的拼串,于是整体优化到 $O(n)$。

### 3.2 核心观察:环形相邻对与「切一刀」

把 $s$ 的下标 $0, 1, \dots, n-1$ 看成一个**环**,定义 $n$ 个**循环相邻对**:

$$(i,\ (i+1) \bmod n),\quad i = 0, 1, \dots, n-1$$

设其中字符相等的对有 $C$ 个。

移位 $r$(把长度 $r$ 的前缀移到末尾)相当于在环上**下标 $r-1$ 与 $r$ 之间切一刀**,再沿环展开成线性串。切开之后:

- 被切断的循环对 $(r-1,\ r)$ 在新串中**不再相邻**;
- 其余 $n-1$ 个循环对(包括跨接缝的 $(n-1, 0)$)在新串中**恰好是全部相邻对**。

因此得分 = 环上相等对总数 − 「被断开的那对是否相等」:

$$\mathrm{score}(r) = C - \mathbb{1}\big[\,s[(r-1+n) \bmod n] = s[r]\,\big]$$

其中 $\mathbb{1}[\cdot]$ 为指示函数,条件成立时取 $1$,否则取 $0$。

> 💡 **一句话总结**:所有移位的得分都是「环上相等对数 $C$ 减去被切口断掉的那一对」,预处理 $C$ 后每个移位 $O(1)$ 出答案。

![环形相邻对与切口示意](images/c518_rotation_ring_concept.svg)

### 3.3 算法流程

1. 遍历环上 $n$ 个循环对,统计字符相等的对数 $C$;
2. 枚举 $r = 0, 1, \dots, n-1$,用上面的公式算出 $\mathrm{score}(r)$;
3. 统计 $\mathrm{score}(r) = k$ 的 $r$ 的个数并返回。

### 3.4 示例演算

以示例 1($s = \text{"aab"}$, $k = 1$,$n = 3$)为例。环上三对:$(0,1)$ 为 a=a ✓、$(1,2)$ 为 a≠b、$(2,0)$ 为 b≠a,故 $C = 1$。

| $r$ | 移位串 | 被断开的对 | 是否相等 | $\mathrm{score}(r)$ | $= k$? |
|-----|--------|-----------|---------|---------------------|--------|
| 0 | aab | $(2,0)$:b≠a | 否 | $1 - 0 = 1$ | ✓ |
| 1 | aba | $(0,1)$:a=a | 是 | $1 - 1 = 0$ | ✗ |
| 2 | baa | $(1,2)$:a≠b | 否 | $1 - 0 = 1$ | ✓ |

得分等于 $1$ 的有 $r = 0$ 和 $r = 2$,答案为 $2$。

![示例 1 的枚举演算](images/c518_rotation_example1_walkthrough.svg)

再看示例 2($s = \text{"abca"}$, $k = 0$):环上只有对 $(3,0)$ 的 a=a 相等,$C = 1$。$r = 0$ 时断开 $(3,0)$,得分 $0$;$r = 1, 2, 3$ 断开的对 $(0,1)$、$(1,2)$、$(2,3)$ 都不相等,得分均为 $1$。等于 $0$ 的只有 $1$ 个,答案为 $1$。✓

## 4. 算法细节

1. **统计 $C$**:对 $i = 0 \dots n-1$ 检查 $s[i] = s[(i+1) \bmod n]$,累计相等对数。注意 $i = n-1$ 时对子是 $(n-1, 0)$,正是「首尾环绕」的那一对,必须取模而不能漏掉。

2. **枚举移位 $r$ 并套公式**:移位 $r$ 的切口在下标 $r-1$ 与 $r$ 之间,被断开的是循环对 $((r-1+n) \bmod n,\ r)$。于是

$$\mathrm{score}(r) = C - \mathbb{1}\big[\,s[(r-1+n) \bmod n] = s[r]\,\big]$$

3. **$r = 0$ 的特判**:$r = 0$ 表示不移动,切口在下标 $n-1$ 与 $0$ 之间,被断开的是环绕对 $(n-1, 0)$。公式中写 $(r-1+n) \bmod n$ 即可统一处理,无需单独分支。

4. **计数**:遍历中维护计数器 $\mathrm{ans}$,当 $\mathrm{score}(r) = k$ 时加一,最后返回。

> ⚠️ **易错**:不要漏掉环绕对 $(n-1, 0)$ 对 $C$ 的贡献,也不要在 $r = 0$ 时用 $s[r-1]$ 直接取下标(C++ 中会得到 $-1$,行为未定义)。

## 5. 正确性证明

**引理 1**:移位 $r$ 后字符串的 $n-1$ 个相邻位置对,与「$n$ 个循环相邻对去掉对 $(r-1,\ r)$」一一对应(下标均在模 $n$ 意义下)。

**证明**:移位 $r$ 后的字符串为 $t = s[r] s[r+1] \cdots s[n-1]\, s[0] s[1] \cdots s[r-1]$。$t$ 的相邻对分三段:

- 前半段内部:$(s[r+j],\ s[r+j+1])$,$j = 0 \dots n-r-2$,即循环对 $(r, r+1), \dots, (n-2, n-1)$;
- 接缝处:$(s[n-1],\ s[0])$,即循环对 $(n-1, 0)$;
- 后半段内部:$(s[j],\ s[j+1])$,$j = 0 \dots r-2$,即循环对 $(0,1), \dots, (r-2, r-1)$。

三段合起来恰好是全部 $n$ 个循环对中去掉 $(r-1, r)$ 后的 $n-1$ 个,且与 $t$ 的 $n-1$ 个相邻位置一一对应。∎

**定理**:算法返回的值等于得分恰好为 $k$ 的移位数量。

**证明**:由引理 1,移位 $r$ 的相邻对集合 = 循环对集合 $\setminus$ $\{(r-1, r)\}$。得分是相邻对中字符相等的对数,因此

$$\mathrm{score}(r) = \underbrace{\sum_{i=0}^{n-1} \mathbb{1}[\,s[i] = s[(i+1) \bmod n]\,]}_{=\,C} - \mathbb{1}\big[\,s[(r-1+n) \bmod n] = s[r]\,\big]$$

即算法使用的公式,故算法对每个 $r$ 算出的得分与题目定义完全一致。算法枚举了全部 $n$ 个移位($r = 0 \dots n-1$ 与题目的 $n$ 种移位一一对应),并对每个移位判断得分是否等于 $k$,计数不重不漏,返回值即为所求。∎

## 6. 复杂度分析

- **时间复杂度**:$O(n)$。统计 $C$ 需一次 $O(n)$ 扫描,枚举 $n$ 个移位时每个移位 $O(1)$ 套公式。
- **空间复杂度**:$O(1)$。只需常数个计数变量,无需存储任何移位结果。

作为对比,暴力拼串重算得分为 $O(n^2)$,在 $n \le 100$ 的约束下同样可通过;$O(n)$ 公式法的价值在于把每个移位的得分降到 $O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int countRotations(string s, int k) {
        int n = s.size();
        int C = 0; // 环上字符相等的循环对总数
        for (int i = 0; i < n; i++)
            if (s[i] == s[(i + 1) % n])
                C++;
        int ans = 0;
        for (int r = 0; r < n; r++) {
            // 移位 r 断开的循环对是 ((r-1+n)%n, r)
            int score = C - (s[(r - 1 + n) % n] == s[r] ? 1 : 0);
            if (score == k)
                ans++;
        }
        return ans;
    }
};
```

### Python

```python
class Solution:
    def countRotations(self, s: str, k: int) -> int:
        n = len(s)
        # 环上字符相等的循环对总数
        C = sum(1 for i in range(n) if s[i] == s[(i + 1) % n])
        ans = 0
        for r in range(n):
            # 移位 r 断开的循环对是 ((r-1+n)%n, r)
            score = C - (1 if s[(r - 1 + n) % n] == s[r] else 0)
            if score == k:
                ans += 1
        return ans
```

## 8. 边界情况与易错点

1. **$r = 0$ 的下标越界**:$r = 0$ 时被断开的是环绕对 $(n-1, 0)$,必须写成 $(r - 1 + n) \bmod n$。若直接写 $s[r-1]$,Python 会错误地取到 $s[-1]$(逻辑错),C++ 则是下标 $-1$ 的未定义行为。

2. **漏掉环绕对对 $C$ 的贡献**:统计 $C$ 时 $i$ 必须取到 $n-1$ 并检查 $s[n-1]$ 与 $s[0]$。漏掉它会使所有得分整体少 $1$。

3. **得分不含首尾环绕对**:题目得分只数线性串的 $n-1$ 对相邻位置,不包括移位后串的首尾。因此 $C$ 是得分的**上界**,当切口断开的对恰好相等时才减 $1$。

4. **全部字符相同**:如 $s = \text{"aaa"}$,此时 $C = n$,无论切口在哪,断开的对都相等,所有移位得分都是 $n-1$。答案为 $n$(当 $k = n-1$)或 $0$(否则)。

5. **答案可以为 $0$**:$k$ 的取值范围是 $0 \le k \le n-1$,若没有任何移位得分等于 $k$,返回 $0$,不要误以为是非法输入。

6. **$n = 2$ 的最小情形**:环上两对 $(0,1)$ 与 $(1,0)$ 涉及同一对字符,要么都算相等要么都不等,公式依然成立,无需特判。
