# LeetCode 统计特殊整数个数 题解

## 1. 题目概述

- **标题 / 题号**：统计特殊整数个数（#4038，easy）
- **链接**：https://leetcode.cn/problems/count-integers-appearing-in-a-single-block/
- **来源**：LeetCode 第 517 场周赛 Q1
- **难度**：简单
- **标签**：数组、哈希表、一次遍历

**题意**：给定整数数组 `nums`。若整数 `x` 在 `nums` 中的**所有**出现位置构成一个**连续**区间（中间无空洞），则称 `x` 为「特殊整数」。返回 `nums` 中**不同**特殊整数的数量。

**约束**：

- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 100`

## 2. 示例

**示例 1**

```text
输入：nums = [1, 2, 2, 1]
输出：1
解释：1 出现在下标 0 和 3，中间隔着别的元素，出现区间断裂，不是特殊整数；
      2 只出现在下标 [1, 2]，连续，是特殊整数。
```

**示例 2**

```text
输入：nums = [3, 3, 1, 2, 2, 1]
输出：2
解释：3 → 下标 [0, 1] 连续 ✓；2 → 下标 [3, 4] 连续 ✓；
      1 → 下标 2 和 5，中间隔着 2，断裂 ✗。
```

## 3. 解题思路

### 3.1 暴力思路

对每个不同的值 `x`，记录其首次出现位置 `first[x]` 与末次出现位置 `last[x]`，再检查区间 `[first[x], last[x]]` 内是否**全部**等于 `x`。值域 $U \le 100$，总复杂度 $O(U \cdot n)$，本题数据下完全够用。

### 3.2 核心观察：只需要「上次出现的位置」

「所有出现位置连续」等价于：**任意相邻两次出现的位置下标之差恰为 1**。

于是只需一次遍历，维护每个值上次出现的下标 `last[x]`：

- 当前扫描到下标 `i`，值为 `x`；
- 若 `x` 之前出现过且 $last[x] \ne i - 1$，说明两次出现之间必然隔着**非 `x`** 的元素（`last[x]` 是最近一次出现，中间不可能再有 `x`），出现区间从此**永久断裂**；
- 断裂不可逆：之后再连续也无法恢复，因此把 `x` 打入「死亡集合」即可。

![特殊整数：出现区间的连续性](images/wc517_q1_interval_model.svg)

### 3.3 算法流程（一次遍历状态机）

```text
初始化：last = {}（值 → 上次出现下标），dead = {}（已断裂的值集合）
遍历 i = 0 .. n-1，设 x = nums[i]：
    若 x ∈ last 且 last[x] != i-1：将 x 加入 dead   # 区间断裂，永久不特殊
    last[x] = i
答案 = 不同值的总数 − |dead|
```

### 3.4 示例演算

以 `nums = [3, 3, 1, 2, 2, 1]` 为例：

| i | nums[i] | 判断 | 动作 | dead |
|---|---------|------|------|------|
| 0 | 3 | 首次出现 | last[3]=0 | {} |
| 1 | 3 | last[3]=0=i−1 | 连续，last[3]=1 | {} |
| 2 | 1 | 首次出现 | last[1]=2 | {} |
| 3 | 2 | 首次出现 | last[2]=3 | {} |
| 4 | 2 | last[2]=3=i−1 | 连续，last[2]=4 | {} |
| 5 | 1 | last[1]=2 ≠ 4 | **断裂**，last[1]=5 | {1} |

不同值 `{3, 1, 2}` 共 3 个，扣除 dead 中 1 个，答案为 $3 - 1 = 2$。✓

## 4. 算法细节

1. **数据结构**：`last` 用哈希表（值域只有 100，也可直接开长度 101 的数组）；`dead` 用集合（或布尔数组）。
2. **首次出现不判断**：`x` 不在 `last` 中时直接记录，不可能构成断裂。
3. **dead 不可逆**：一旦断裂，后续即使连续出现也保持 dead 状态，绝不能从 dead 中移除。
4. **答案统计**：$\text{len}(\text{set}(nums)) - \text{len}(dead)$；也可在遍历中用三态（未出现 / 块中 / 已断裂）计数，本质相同。

## 5. 正确性证明

**引理 1**：`x` 是特殊整数 ⟺ `x` 的任意相邻两次出现位置 $p_k, p_{k+1}$ 满足 $p_{k+1} = p_k + 1$。

**证明**：
（⇒）设出现位置集合为连续区间，即 $m$ 个出现位置恰好铺满 $[p_1, p_m]$，无空洞，故相邻位置差为 1。
（⇐）若所有相邻出现位置差均为 1，则出现位置是公差为 1 的等差数列，即铺满区间 $[p_1, p_m]$，无空洞，`x` 特殊。∎

**定理**：算法返回值等于特殊整数的个数。

**证明**：`x` 被放入 `dead` 当且仅当存在相邻两次出现 $p_k < p_{k+1}$ 且 $p_{k+1} > p_k + 1$——因为 `last[x]` 记录的是最近一次出现，`last[x] != i-1` 即两次出现之间至少隔一个位置。由引理 1，此时 `x` 不特殊。反之，若 `x` 不特殊，必存在这样的断裂点，遍历到 $p_{k+1}$ 时 `x` 必然已（或恰好）进入 `dead`。故 `dead` 恰为全体不特殊值，答案 = 不同值数 − 不特殊值数。∎

## 6. 复杂度分析

- **时间复杂度**：$O(n)$。每个元素一次哈希表查询与更新。
- **空间复杂度**：$O(U)$，$U$ 为值域大小（本题 `nums[i] <= 100`，可视为常数）。

## 7. 参考代码

### C++

```cpp
class Solution {
  public:
    int countSpecialIntegers(vector<int>& nums) {
        int n = nums.size();
        vector<int> last(101, -1);
        vector<bool> dead(101, false);
        for (int i = 0; i < n; i++) {
            int x = nums[i];
            if (last[x] != -1 && last[x] != i - 1)
                dead[x] = true;
            last[x] = i;
        }
        int ans = 0;
        for (int x = 1; x <= 100; x++)
            if (last[x] != -1 && !dead[x])
                ans++;
        return ans;
    }
};
```

### Python

```python
class Solution:
    def countSpecialIntegers(self, nums: List[int]) -> int:
        last = {}
        dead = set()
        for i, x in enumerate(nums):
            if x in last and last[x] != i - 1:
                dead.add(x)
            last[x] = i
        return len(set(nums) - dead)
```

## 8. 边界情况与易错点

1. **全部相同**：如 `[7, 7, 7]`，每次出现都相邻，答案为 1。
2. **只出现一次的值必特殊**：不存在「相邻两次出现」，不会进 dead。
3. **断裂后又连续出现**：如 `[1, 2, 1, 1]`，`1` 在下标 2 处断裂，下标 3 虽与 2 相邻，但 `1` 已永久不特殊——dead 不能移除。
4. **首次出现的判断顺序**：`x in last` 为假时是首次出现，不能误判为断裂。
5. **统计口径是「不同」整数**：重复出现的特殊整数只计一次。
6. **别把「区间内全是 x」误写成「区间内出现过 x」**：暴力法检查的是区间**每个**位置都等于 `x`。
