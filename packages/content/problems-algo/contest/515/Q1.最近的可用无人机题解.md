# LeetCode 最近的可用无人机 题解

## 1. 题目概述

- **标题 / 题号**：最近的可用无人机（#4024，easy）
- **链接**：https://leetcode.cn/problems/nearest-available-drone/
- **来源**：LeetCode 第 515 场周赛 Q1
- **难度**：简单
- **标签**：数组、遍历、曼哈顿距离

**题意**：给定无人机数组 `drones`，每架 `drones[i] = [xi, yi, rangei]` 表示坐标与飞行范围。给定目标 `target = [tx, ty]`。若无人机到目标的曼哈顿距离 $\le$ `rangei` 则可达。返回可达且距离最小的无人机下标（相同取最小下标），无可达则返回 $-1$。

**约束**：

- $1 \le \text{drones.length} \le 100$
- $-25 \le x_i, y_i, t_x, t_y \le 25$
- $1 \le \text{range}_i \le 100$

## 2. 示例

**示例 1**

```text
输入：drones = [[0,0,8],[2,2,9]], target = [3,4]
输出：1
解释：drone[0] 距离 7 <= 8 可达；drone[1] 距离 3 <= 9 可达且更近，返回 1。
```

**示例 2**

```text
输入：drones = [[2,1,5],[4,4,5],[6,6,8]], target = [5,5]
输出：1
解释：drone[0] 距离 7 > 5 不可达；drone[1] 和 drone[2] 距离均为 2，取最小下标 1。
```

## 3. 解题思路

### 3.1 核心观察：一次遍历

![最近无人机：曼哈顿距离 + 飞行范围过滤](images/wc515_q1_drone_select.svg)

逐架遍历，计算曼哈顿距离 $d = |x_i - t_x| + |y_i - t_y|$。若 $d \le \text{range}_i$，则该无人机可达，与当前最优比较：$d$ 更小则更新，$d$ 相等则不更新（保留更小下标）。

### 3.2 算法流程

1. `best_idx = -1`, `best_dist = +∞`。
2. 遍历每架无人机：计算 $d$，若 $d \le \text{range}$ 且 $d < \text{best\_dist}$，更新 `best_dist = d`, `best_idx = i`。
3. 返回 `best_idx`。

## 4. 算法细节

- 曼哈顿距离：$|x_i - t_x| + |y_i - t_y|$，坐标范围 $[-25, 25]$，距离最大 $100$，`int` 足够。
- **距离相等取最小下标**：用严格小于 `<` 比较，使得后出现的等距无人机不覆盖先出现的。

## 5. 正确性证明

**定理**：一次遍历取 $d \le \text{range}$ 中 $d$ 最小且下标最小的无人机。

**证明**：遍历覆盖所有无人机。对每架判断可达性（$d \le \text{range}$），可达时与最优比较。用 `<` 严格比较保证等距保留下标更小者。无可达时 `best_idx` 保持 $-1$。$\square$

## 6. 复杂度分析

- **时间复杂度**：$O(n)$，一次遍历。
- **空间复杂度**：$O(1)$。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    int nearestDrone(vector<vector<int>>& drones, vector<int>& target) {
        int best_idx = -1, best_dist = INT_MAX;
        int tx = target[0], ty = target[1];
        for (int i = 0; i < (int)drones.size(); ++i) {
            int d = abs(drones[i][0] - tx) + abs(drones[i][1] - ty);
            if (d <= drones[i][2] && d < best_dist) {
                best_dist = d;
                best_idx = i;
            }
        }
        return best_idx;
    }
};
```

### Python

```python
class Solution:
    def nearestDrone(self, drones: list[list[int]], target: list[int]) -> int:
        best_idx = -1
        best_dist = float('inf')
        tx, ty = target
        for i, (x, y, r) in enumerate(drones):
            d = abs(x - tx) + abs(y - ty)
            if d <= r and d < best_dist:
                best_dist = d
                best_idx = i
        return best_idx
```

## 8. 边界情况与易错点

1. **无无人机可达**：返回 $-1$，`best_idx` 初始值。
2. **等距取最小下标**：用 `<` 而非 `<=` 比较 `best_dist`。
3. **坐标为负**：曼哈顿距离用 `abs`，正负坐标均可。
4. **单架无人机**：若可达返回 $0$，否则 $-1$。
