# LeetCode 数对的最大强度 题解

## 1. 题目概述

- **标题 / 题号**：数对的最大强度（#101132，easy）
- **链接**：https://leetcode.cn/problems/maximize-pair-strength-using-gcd/
- **来源**：LeetCode 第 513 场周赛 Q1
- **难度**：简单
- **标签**：数学、gcd、暴力枚举

**题意**：给定整数数组 `nums`，选**恰好一对**不同下标 $i, j$，数对强度定义为

$$\text{strength} = \frac{\text{nums}[i] \cdot \text{nums}[j]}{\gcd(\text{nums}[i], \text{nums}[j])^2}$$

返回所有可能数对中的**最大**强度。

**约束**：

- $2 \le \text{nums.length} \le 2000$
- $1 \le \text{nums}[i] \le 10^5$

## 2. 示例

**示例 1**

```text
输入：nums = [2,3,5]
输出：15
解释：选 (3,5)，gcd=1，强度 = 3·5/1 = 15。
```

**示例 2**

```text
输入：nums = [4,6,8]
输出：12
解释：选 (6,8)，gcd=2，强度 = 6·8/4 = 12。
```

**示例 3**

```text
输入：nums = [3,3]
输出：1
解释：选 (3,3)，gcd=3，强度 = 9/9 = 1。
```

## 3. 解题思路

### 3.1 暴力思路

$n \le 2000$，数对数 $\binom{n}{2} \approx 2 \times 10^6$，每对算一次 gcd，总复杂度 $O(n^2 \log V)$，可接受。这就是签到题的最短路径。

### 3.2 核心观察：化简强度公式

![强度公式化简：约掉公共因子 g，只看互质的“核”](images/pair_strength_formula.svg)

设 $g = \gcd(a, b)$，把公共因子拆出来：$a = g \cdot u$，$b = g \cdot v$，其中 $\gcd(u, v) = 1$。代入强度定义：

$$\text{strength} = \frac{(g u)(g v)}{g^2} = u \cdot v = \frac{a}{g} \cdot \frac{b}{g}$$

即**公共因子 $g$ 被完全约掉，强度只取决于两个数去掉最大公因子后的“核”之积**。这等价于 $\text{lcm}(a,b) / \gcd(a,b)$。

### 3.3 为什么不能贪心取最大两数

![反例：取最大两数不一定最优](images/pair_strength_walkthrough.svg)

直觉上想选最大的两个数，但公因子会“吃掉”强度。反例 `[6, 10, 15]`：最大两数 $10, 15$，$g=5$，强度 $= 2 \cdot 3 = 6$；而 $6, 10$，$g=2$，强度 $= 3 \cdot 5 = 15$ 更大。因此**必须枚举所有数对**。

### 3.4 算法流程

1. 初始化 `ans = 0`。
2. 双重循环枚举 $0 \le i < j < n$：
   - $g = \gcd(\text{nums}[i], \text{nums}[j])$
   - $\text{val} = (\text{nums}[i] / g) \cdot (\text{nums}[j] / g)$（先除后乘，避免溢出）
   - `ans = max(ans, val)`
3. 返回 `ans`。

## 4. 算法细节

1. **先除后乘**：$\text{nums}[i] \le 10^5$，直接 $a \cdot b$ 可达 $10^{10}$，C++ `int` 会溢出；先各除以 $g$ 得 $u, v \le 10^5$，再 $u \cdot v \le 10^{10}$，仍需 `long long`。但先除后乘让中间值更小、语义更清晰。
2. **整数除法无误差**：$g$ 是 $a, b$ 的公约数，$a/g$ 与 $b/g$ 都是整数。
3. **去重不影响**：即使数组有重复值（如 `[3,3]`），枚举不同下标即可，无需去重。

## 5. 正确性证明

**引理**：$\frac{a \cdot b}{\gcd(a,b)^2} = \frac{a}{g} \cdot \frac{b}{g}$，其中 $g = \gcd(a,b)$。

**证明**：令 $a = g u$，$b = g v$，$\gcd(u,v)=1$（由 $g$ 为最大公约数保证）。则 $\frac{a b}{g^2} = \frac{g^2 u v}{g^2} = u v = \frac{a}{g}\cdot\frac{b}{g}$。$\square$

**定理**：枚举所有数对取最大值即为答案。

**证明**：题目要求“恰好一对不同下标”的最大强度。由引理，每对强度可由公式精确计算；枚举 $\binom{n}{2}$ 个数对覆盖所有合法选择，取最大值即为全局最大。$\square$

## 6. 复杂度分析

- **时间复杂度**：$O(n^2 \log V)$，$V = 10^5$。数对数 $\sim 2 \times 10^6$，每对 gcd $O(\log V) \approx 17$，总计 $\sim 3.4 \times 10^7$ 次运算。
- **空间复杂度**：$O(1)$，仅用常数变量。

> 💡 C++ 约 20–40 ms；Python 用 `math.gcd`（C 实现）约 0.5–1 s，可过。

## 7. 参考代码

### C++

```cpp
class Solution {
public:
    long long maxStrength(vector<int>& nums) {
        int n = nums.size();
        long long ans = 0;
        for (int i = 0; i < n; ++i) {
            for (int j = i + 1; j < n; ++j) {
                int g = gcd(nums[i], nums[j]);
                long long u = nums[i] / g;
                long long v = nums[j] / g;
                ans = max(ans, u * v);
            }
        }
        return ans;
    }
};
```

### Python

```python
import math

class Solution:
    def maxStrength(self, nums: list[int]) -> int:
        ans = 0
        n = len(nums)
        for i in range(n):
            for j in range(i + 1, n):
                g = math.gcd(nums[i], nums[j])
                ans = max(ans, (nums[i] // g) * (nums[j] // g))
        return ans
```

## 8. 边界情况与易错点

1. **$n = 2$**：唯一一对，直接返回其强度。
2. **两数相同**（`[3,3]`）：$g = a$，$u = v = 1$，强度 $= 1$，勿误认为 $a^2$。
3. **整数溢出**：$u \cdot v$ 可达 $10^{10}$，C++ 必须用 `long long` 存结果与中间乘积。
4. **先除后乘**：避免 $a \cdot b$ 中间溢出（本题 $10^{10}$ 已超 32 位 int）。
5. **下标不同即可**：值相同但下标不同是合法数对。
