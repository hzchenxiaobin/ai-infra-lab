# LeetCode 最深叶节点的最近公共祖先 题解

## 1. 题目概述

- **标题 / 题号**：最深叶节点的最近公共祖先（#1123，medium）
- **链接**：https://leetcode.cn/problems/lowest-common-ancestor-of-deepest-leaves/
- **难度**：中等
- **标签**：树、二叉树、深度优先搜索、后序遍历、最近公共祖先

**题意**：给定一棵二叉树的根节点 `root`，返回其**最深叶子节点**的**最近公共祖先**（Lowest Common Ancestor, LCA）。

> **叶子节点**：没有孩子的节点。
> **最深叶子节点**：树中深度最大的所有叶子节点（深度从根算起，根的深度为 $0$）。可能有多个处于同一最大深度的叶子。
> **最近公共祖先**：一个节点自身也可以是它自己的祖先。一组节点 $S$ 的 LCA 是**深度最大**的那个「以 $S$ 中所有节点为后代」的节点。

**示例 1**：

```text
输入：root = [3,5,1,6,2,0,8,null,null,7,4]
输出：[2]

            3
          /   \
         5     1
        / \   / \
       6   2 0   8
          / \
         7   4
```

最深叶子为 `7` 和 `4`（深度均为 $3$），它们的 LCA 是节点 `2`。

**示例 2**：

```text
输入：root = [1]
输出：[1]
```

只有一个节点，它本身就是最深叶子，LCA 为自身。

**示例 3**：

```text
输入：root = [0,1,3,null,2]
输出：[2]

        0
       / \
      1   3
       \
        2
```

最深叶子为 `2`（深度 $2$），它是唯一的最深叶子，LCA 为自身 `2`。

**约束**：

- 树中节点数目范围 $[1, 1000]$
- $0 \le \text{Node.val} \le 1000$
- 每个节点的值**互不相同**

> 💡 本题的核心是：**先确定哪些叶子最深，再求它们的 LCA**。难点在于这两件事看似需要分两趟遍历，但只要把「子树最深叶子的深度」与「该子树中最深叶子的 LCA」打包成一个返回值，就能在**一次后序 DFS** 中同时完成。

## 2. 解题思路

### 2.1 暴力思路：两趟遍历

第一趟 BFS/DFS 求出最大深度 `maxDepth`，并收集所有深度等于 `maxDepth` 的叶子节点集合 $S$；第二趟求 $S$ 中所有节点的 LCA。

求多节点 LCA 的常规做法是：DFS 统计当前子树中包含 $S$ 中节点的个数 `cnt`，**第一个**满足 `cnt == |S|` 的节点即为 LCA。这需要把集合 $S$ 转成哈希集合 $O(1)$ 查询，整体两趟各 $O(n)$，共 $O(n)$，**但常数较大、逻辑割裂**——先求深度再求 LCA 是两个独立的关注点，且要额外存集合 $S$。

> ⚠️ 若退化为「两两合并 LCA」（$\text{LCA}(S)=\text{LCA}(\text{LCA}(n_1,n_2),n_3)\dots$），每次 LCA 查询 $O(n)$，共 $k-1$ 次（$k=|S|$），最坏满树 $k=O(n)$，总复杂度退化到 $O(n^2)$。

### 2.2 核心观察：一次后序 DFS 返回 (depth, lca)

![核心观察：最深节点的最小子树 = 所有最深节点的 LCA](../images/deepest_subtree_concept.svg)

**关键洞察**：对于任意节点 `node`，我们关心它的子树里两件事——

> ① 这棵子树里**最深叶子**的深度 `depth`（即从 `node` 到其子树最深叶子的层数）；
> ② 这棵子树里**所有最深叶子**的 LCA `lca`。

这两者都具备**最优子结构**，可以在后序遍历中由左右孩子的返回值 $O(1)$ 合成：

| 左右孩子深度关系 | 含义 | 当前节点的返回值 |
|------------------|------|------------------|
| `ld == rd` | 最深叶子**分布在两侧** | `(ld + 1, node)`——当前节点把两侧的最深叶子「拉到一起」，它就是它们的 LCA |
| `ld > rd` | 最深叶子**只在左侧** | `(ld + 1, ln)`——沿用左子树的 LCA，右侧够不到最深 |
| `ld < rd` | 最深叶子**只在右侧** | `(rd + 1, rn)`——沿用右子树的 LCA，左侧够不到最深 |

其中 `(ld, ln) = dfs(node.left)`、`(rd, rn) = dfs(node.right)`。

> ⚠️ **为什么 `ld == rd` 时 LCA 就是当前节点？** 因为两侧都各自有最深叶子，且它们的深度相同——这意味着整棵子树的最深叶子**横跨左右两支**，能把它们「合流」的最高节点正是当前 `node`。再往上走，它的祖先只能覆盖到其中一侧（或都不覆盖），无法同时作为两侧最深叶子的祖先，故当前节点已是 LCA。

### 2.3 算法流程图

![算法流程：dfs(node) 返回 (depth, lca)](../images/deepest_subtree_flow.svg)

**`dfs(node)` 完整步骤**：

1. **空节点**：返回 `(0, null)`——空子树无叶子，深度记 $0$，LCA 为空；
2. **递归左**：`(ld, ln) = dfs(node.left)`；
3. **递归右**：`(rd, rn) = dfs(node.right)`；
4. **三路判定**（见上表）：
   - `ld == rd` → 返回 `(ld + 1, node)`；
   - `ld > rd`  → 返回 `(ld + 1, ln)`；
   - `ld < rd`  → 返回 `(rd + 1, rn)`；
5. **最终答案**：`dfs(root)` 返回的 `lca` 即为整棵树最深叶子的 LCA。

> 💡 **深度约定**：空节点深度 $0$，叶子深度 $1$（深度 $=$ 从该节点到子树最深叶子的**节点数**，含自身）。`+1` 的含义是「当前节点把深度又往下垫了一层」。这个约定下，`ld == rd` 时两侧最深叶子位于同一层，当前节点恰好是它们的合流点。

### 2.4 示例演算

以 `root = [3,5,1,6,2,0,8,null,null,7,4]` 为例，后序访问顺序为 `6 → 7 → 4 → 2 → 5 → 0 → 8 → 1 → 3`：

![示例演算：逐节点 (depth, lca) 自底向上汇聚](../images/deepest_subtree_walkthrough.svg)

| 步骤 | 节点 | 左返回 | 右返回 | 决策 | 返回 (d, lca) |
|------|------|--------|--------|------|---------------|
| ① | 6 (叶) | (0, null) | (0, null) | 等深→自身 | (1, 6) |
| ② | 7 (叶) | (0, null) | (0, null) | 等深→自身 | (1, 7) |
| ③ | 4 (叶) | (0, null) | (0, null) | 等深→自身 | (1, 4) |
| ④ | 2 | (1, 7) | (1, 4) | 等深→自身 | (2, **2**) ⭐ |
| ⑤ | 5 | (1, 6) | (2, 2) | 右深→传右 | (3, 2) |
| ⑥ | 0 (叶) | (0, null) | (0, null) | 等深→自身 | (1, 0) |
| ⑦ | 8 (叶) | (0, null) | (0, null) | 等深→自身 | (1, 8) |
| ⑧ | 1 | (1, 0) | (1, 8) | 等深→自身 | (2, 1) |
| ⑨ | 3 (根) | (3, 2) | (2, 1) | 左深→传左 | (4, **2**) ✅ |

> 💡 **观察步骤 ④**：节点 `2` 的左右孩子 `7`、`4` 都是深度 $1$ 的叶子且等深，于是 `2` 把它们合流，返回 `(2, 2)` 成为候选 LCA。之后步骤 ⑤ 中节点 `5` 发现右侧（含 `2`）比左侧（`6`）更深，于是把候选 `2` 继续向上透传；步骤 ⑨ 根 `3` 发现左侧（深度 $3$）深于右侧（深度 $2$），最终答案锁定为 `2`。整个过程**只有一次「合流」发生**，其余都是单侧透传。

## 3. 参考代码

### C++

```cpp
class Solution {
public:
    TreeNode* lcaDeepestLeaves(TreeNode* root) {
        return dfs(root).second;
    }

    pair<int, TreeNode*> dfs(TreeNode* node) {
        if (!node) return {0, nullptr};
        auto [ld, ln] = dfs(node->left);
        auto [rd, rn] = dfs(node->right);
        if (ld == rd) return {ld + 1, node};   // 两侧等深 → 当前节点合流
        if (ld > rd)  return {ld + 1, ln};      // 仅左侧最深 → 透传左 LCA
        return {rd + 1, rn};                    // 仅右侧最深 → 透传右 LCA
    }
};
```

### Python

```python
class Solution:
    def lcaDeepestLeaves(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        def dfs(node: Optional[TreeNode]) -> tuple[int, Optional[TreeNode]]:
            if not node:
                return (0, None)
            ld, ln = dfs(node.left)
            rd, rn = dfs(node.right)
            if ld == rd:
                return (ld + 1, node)          # 两侧等深 → 当前节点合流
            if ld > rd:
                return (ld + 1, ln)             # 仅左侧最深 → 透传左 LCA
            return (rd + 1, rn)                 # 仅右侧最深 → 透传右 LCA

        return dfs(root)[1]
```

> 💡 **实现细节**：① `dfs` 返回 `(depth, lca)` 二元组，`depth` 用 `int`、`lca` 用节点指针，父节点直接解构复用。② 三路判定用 `if/else if/else` 覆盖全部情况，无需额外分支。③ 空节点返回 `(0, nullptr)`：深度 $0$ 比任何真实节点（$\ge 1$）都小，保证「单侧透传」时另一侧的空不会误触发等深合流。④ 最终答案取 `dfs(root).second`，根的 `depth` 字段无需关心。

## 4. 复杂度分析

| 维度 | 复杂度 | 说明 |
|------|--------|------|
| 时间复杂度 | $O(n)$ | 每个节点只访问一次，三路判定与返回值合并均 $O(1)$ |
| 空间复杂度 | $O(h)$ | 递归栈深度，$h$ 为树高；平衡树 $O(\log n)$，退化链 $O(n)$ |
| 最坏情况 | $O(n)$ 空间 | 树退化为单侧链时递归深度达 $n$ |

> ⚠️ 暴力两趟法的总复杂度也是 $O(n)$，但需要两趟遍历、维护最深叶子集合、再跑一次「计数控 LCA」。本解法把「深度」与「LCA」**融合成一个返回值**，一次后序 DFS 同时推进，省去集合存储与第二趟遍历，常数更优、逻辑更紧凑。

## 5. 扩展：两趟法（求最深叶子集合 + 计数控 LCA）

若面试官要求「不用一次 DFS 融合」或想体现对 LCA 通用模板的掌握，可用两趟法：

```python
class Solution:
    def lcaDeepestLeaves(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        # 第一趟：求最大深度
        max_depth = -1
        def get_depth(node, d):
            nonlocal max_depth
            if not node:
                return
            if not node.left and not node.right:
                max_depth = max(max_depth, d)
            get_depth(node.left, d + 1)
            get_depth(node.right, d + 1)
        get_depth(root, 0)

        # 第二趟：DFS 计数，第一个 cnt == total 的节点即 LCA
        deepest = set()
        def collect(node, d):
            if not node:
                return
            if not node.left and not node.right and d == max_depth:
                deepest.add(node.val)
            collect(node.left, d + 1)
            collect(node.right, d + 1)
        collect(root, 0)
        total = len(deepest)

        ans = None
        def count(node):
            nonlocal ans
            if not node:
                return 0
            l = count(node.left)
            r = count(node.right)
            cnt = l + r + (1 if node.val in deepest else 0)
            if cnt == total and ans is None:
                ans = node
            return cnt
        count(root)
        return ans
```

> 💡 **两趟法 vs 一趟法**：两趟法思路直白（先找目标再求 LCA），但需三趟遍历（求深度、收集、计数）与一个哈希集合。一趟法把「深度」与「LCA」编码进返回值，**用等深判定取代显式集合**——`ld == rd` 本身就隐含了「两侧各有最深叶子」的信息，无需记录具体是哪些叶子。这正是「状态融合」降低复杂度常数的典型范例。

## 6. 面试要点

1. **为什么一次 DFS 就够？深度和 LCA 怎么融合？**

   > 因为「子树中最深叶子的深度」和「子树中最深叶子的 LCA」都能由左右孩子的对应结果 $O(1)$ 合成：深度取 `max(ld, rd) + 1`；LCA 看两侧深度是否相等——相等则当前节点合流，不等则透传更深一侧的 LCA。把两者打包成 `(depth, lca)` 返回值，后序遍历自底向上一次成型。

2. **`ld == rd` 时为什么 LCA 一定是当前节点，而不是它的某个祖先？**

   > 两侧等深意味着「左右各至少有一个最深叶子且位于同一层」。当前节点是同时覆盖左右两侧最深叶子的**最低**节点；再往上的祖先虽然也能覆盖，但深度更大（更「高」），不符合「最近」（lowest）。而当前节点的孩子只能覆盖一侧，不够「公共」。所以当前节点恰好是「最近公共」的平衡点。

3. **只有一个最深叶子时（如示例 3），算法如何返回它自身？**

   > 沿着那条独占最深路径，每一层都是「单侧更深 → 透传更深侧的 LCA」，最终透传到根的就是那个最深叶子本身。因为它从未遇到「两侧等深」的合流点，LCA 一路就是它自己——这与「单节点集合的 LCA 是自身」一致。

4. **空节点为什么返回 `(0, null)` 而不是 `(−1, null)`？**

   > 深度约定为「从节点到子树最深叶子的节点数」，空子树没有叶子，深度记 $0$（比任何真实节点 $\ge 1$ 都小）。这样当某节点只有一个孩子时，`null` 那侧返回 $0$、真实侧返回 $\ge 1$，必然走「单侧透传」分支，不会误判为等深合流。若用 $-1$ 则叶子（左右都 $-1$）会 `ld==rd==-1` 返回 `(0, 自身)`，需要多一处 `+1` 调整，不如 $0$ 简洁统一。

5. **本题与 865「具有所有最深节点的最小子树」是什么关系？**

   > 完全相同的题目。865 求「包含所有最深节点的最小子树根」，正是所有最深节点的 LCA。两者题面措辞不同、数据范围一致，解法与代码完全通用。

> 💡 **一句话总结**：1123 的灵魂是「**把深度与 LCA 融合成 `(depth, lca)` 返回值，用等深判定替代显式集合**」——`dfs(node)` 后序拿到 `(ld,ln)`、`(rd,rn)`，三路判定：等深则当前节点合流 `(d+1, node)`，否则透传更深侧的 LCA。一次遍历 $O(n)$ 同时锁定最深叶子的深度与它们的公共祖先，是「后序返回元组 + 局部决策」的典范。
