# LeetCode 叶值的最小代价生成树 题解

## 1. 题目概述

- **标题 / 题号**：叶值的最小代价生成树（#1130，medium）
- **链接**：https://leetcode.cn/problems/minimum-cost-tree-from-leaf-values/
- **难度**：中等
- **标签**：动态规划、区间 DP、树、栈

**题意**：给定一个正整数数组 `arr`，考虑所有满足以下条件的二叉树：

- 每个节点有 `0` 个或 `2` 个子节点（满二叉树结构）；
- 数组 `arr` 中的值与树的中序遍历中每个叶节点的值一一对应；
- 每个非叶节点的值 = 其左右子树中叶节点的最大值之乘积。

在所有这样的二叉树中，返回每个非叶节点的值之和的**最小可能总和**。

**示例 1**：

```text
输入：arr = [6, 2, 4]
输出：32
解释：有两种可能的树——
  树 A ((6,2),4)：非叶节点 12 + 24 = 36
  树 B (6,(2,4))：非叶节点 8 + 24 = 32 ← 最优
```

**示例 2**：

```text
输入：arr = [4, 11]
输出：44
解释：只有一个非叶节点，值 = 4 × 11 = 44。
```

**约束**：

- `2 <= arr.length <= 40`
- `1 <= arr[i] <= 15`
- 答案保证是一个 32 位带符号整数（小于 $2^{31}$）

> 💡 本题是**区间 DP** 的经典应用，与 [312. 戳气球](../0301-0400/312_戳气球.md)、[1039. 多边形三角剖分](../1001-1100/1039_多边形三角剖分的最低得分.md) 高度同构——都是「在区间上枚举切分点 $k$，把问题拆成左右两个独立子区间」。区别在于本题的「合并代价」是**左右子区间最大叶值之积**，需额外维护一张 `maxLeaf` 辅助表。此外，本题还有一条 $O(n)$ 的**单调栈**贪心解法（见第 5 节），殊途同归。

## 2. 解题思路

### 2.1 暴力思路：枚举所有树形

数组 `arr` 的中序遍历确定了叶节点顺序，不同的二叉树对应不同的**括号化方案**（即不同的合并顺序）。`n` 个叶节点有 $C_{n-1}$（卡特兰数）种合法树形，`n = 40` 时 $C_{39}$ 是天文数字，必然超时。

关键观察：一旦选定根的切分点 $k$（左子树叶子为 `arr[i..k]`，右子树叶子为 `arr[k+1..j]`），左右子树**完全独立**——这是典型的**分治**结构，适合区间 DP。

### 2.2 核心观察：区间 DP + maxLeaf 辅助表

![核心观察：枚举切分点 k，dp[i][j] = dp[i][k] + dp[k+1][j] + maxLeaf[i][k] × maxLeaf[k+1][j]](../images/mct_concept.svg)

**状态定义**：

$$\text{dp}[i][j] = \text{对叶子数组 } \text{arr}[i..j] \text{ 构建二叉树时，非叶节点值的最小总和}$$

**辅助表**：

$$\text{maxLeaf}[i][j] = \max(\text{arr}[i], \ldots, \text{arr}[j]) \quad \text{（区间内最大叶值）}$$

> ⚠️ **为什么需要 `maxLeaf` 表？** 非叶节点的值 = 左子树最大叶 × 右子树最大叶。根节点的值取决于 `maxLeaf[i][k]` 与 `maxLeaf[k+1][j]`——这两个值由区间本身决定，与子树内部结构无关。预计算 `maxLeaf` 后，转移时 $O(1)$ 取值。

**状态转移**（枚举根的切分点 $k$，$i \le k < j$）：

$$\text{dp}[i][j] = \min_{i \le k < j} \Big\{\, \text{dp}[i][k] + \text{dp}[k+1][j] + \text{maxLeaf}[i][k] \times \text{maxLeaf}[k+1][j] \,\Big\}$$

**转移的直觉**：

| 部分 | 含义 | 来源 |
|------|------|------|
| `dp[i][k]` | 左子树 `[i..k]` 的非叶节点最小和 | **已解决的子问题** |
| `dp[k+1][j]` | 右子树 `[k+1..j]` 的非叶节点最小和 | **已解决的子问题** |
| `maxLeaf[i][k] × maxLeaf[k+1][j]` | 根节点的值（左右最大叶之积） | **当前合并代价** |

**边界**：`dp[i][i] = 0`（单个叶节点，无非叶节点），`maxLeaf[i][i] = arr[i]`。

**答案**：`dp[0][n-1]`。

> 💡 **与 312 戳气球的对比**：312 是「开区间 $(i,j)$ 内最后戳的气球 $k$，贡献 $\text{val}[i] \times \text{val}[k] \times \text{val}[j]$」；本题是「闭区间 $[i,j]$ 的根切分点 $k$，贡献 $\text{maxLeaf}[i][k] \times \text{maxLeaf}[k+1][j]$」。两者都是区间 DP 枚举切分点，但 312 的代价是**三元素乘积**（两端固定），本题的代价是**两区间属性之积**（需辅助表维护）。

### 2.3 算法流程图

![算法流程：初始化 maxLeaf/dp → 按区间长度递增填表 → 枚举切分点 k → 返回 dp[0][n-1]](../images/mct_algorithm_flow.svg)

**完整步骤**：

1. **初始化**：`n = len(arr)`，`dp` 与 `maxLeaf` 均为 $n \times n$ 矩阵，全 0
2. **填 `maxLeaf` 对角线**：`maxLeaf[i][i] = arr[i]`
3. **按区间长度递增**：`len` 从 2 到 `n`：
   - 对每个左端 `i`，令 `j = i + len - 1`
   - **更新 `maxLeaf`**：`maxLeaf[i][j] = max(maxLeaf[i][j-1], arr[j])`
   - `dp[i][j]` 初始化为 $+\infty$
   - **枚举切分点** `k` 从 `i` 到 `j-1`：
     - $\text{dp}[i][j] = \min(\text{dp}[i][j],\ \text{dp}[i][k] + \text{dp}[k+1][j] + \text{maxLeaf}[i][k] \times \text{maxLeaf}[k+1][j])$
4. **返回** `dp[0][n-1]`

> ⚠️ **`maxLeaf` 的填充顺序**：`maxLeaf[i][j]` 依赖 `maxLeaf[i][j-1]`（同行左邻），在按长度递增遍历时 `j-1` 对应更短区间，已提前算好。也可以在 DP 主循环前用双重循环一次性预填完所有 `maxLeaf`。

### 2.4 示例演算

以 `arr = [6, 2, 4]` 为例：

![示例演算：两种树形对比 + dp 填表，答案 dp[0][2]=32](../images/mct_example_walkthrough.svg)

**两种树形对比**：

| 树形 | 根切分点 | 根值 | 内部节点值 | 总和 |
|------|----------|------|-----------|------|
| 树 A `((6,2),4)` | $k=1$ | $6 \times 4 = 24$ | $6 \times 2 = 12$ | 36 |
| 树 B `(6,(2,4))` | $k=0$ | $6 \times 4 = 24$ | $2 \times 4 = 8$ | **32** ✓ |

> 💡 **关键洞察**：两棵树的根值都是 $6 \times 4 = 24$（根总是用全区间最大叶 6 和 4），但内部节点不同——树 B 把小值 2 和 4 组合产生 $2 \times 4 = 8$，远小于树 A 的 $6 \times 2 = 12$。**让大值尽可能晚地参与乘法**是降低总和的核心直觉。

**`maxLeaf` 表**：

| | `j=0` | `j=1` | `j=2` |
|------|-------|-------|-------|
| `i=0` | 6 | 6 | 6 |
| `i=1` | — | 2 | 4 |
| `i=2` | — | — | 4 |

**`dp` 表**（按长度递增填充）：

| 区间 | 长度 | 枚举 $k$ | 计算 | `dp[i][j]` |
|------|------|----------|------|-----------|
| `[0,0]` | 1 | — | 边界 | 0 |
| `[1,1]` | 1 | — | 边界 | 0 |
| `[2,2]` | 1 | — | 边界 | 0 |
| `[0,1]` | 2 | $k=0$ | $0 + 0 + 6 \times 2 = 12$ | **12** |
| `[1,2]` | 2 | $k=1$ | $0 + 0 + 2 \times 4 = 8$ | **8** |
| `[0,2]` | 3 | $k=0$ | $0 + 8 + 6 \times 4 = 32$ | |
| | | $k=1$ | $12 + 0 + 6 \times 4 = 36$ | **32** ✓ |

最终 `dp[0][2] = 32`，对应树 B `(6,(2,4))`。

## 3. 参考代码

### C++

```cpp
// 叶值的最小代价生成树.cpp —— 区间 DP + maxLeaf 辅助表
// 编译: g++ -O2 -std=c++17 叶值的最小代价生成树.cpp -o mct
class Solution {
public:
    int mctFromLeafValues(vector<int>& arr) {
        int n = arr.size();
        vector<vector<int>> dp(n, vector<int>(n, 0));
        vector<vector<int>> maxLeaf(n, vector<int>(n, 0));

        for (int i = 0; i < n; i++) {
            maxLeaf[i][i] = arr[i];
        }

        for (int len = 2; len <= n; len++) {         // 区间长度
            for (int i = 0; i + len - 1 < n; i++) {  // 左端
                int j = i + len - 1;                 // 右端
                maxLeaf[i][j] = max(maxLeaf[i][j - 1], arr[j]);
                dp[i][j] = INT_MAX;
                for (int k = i; k < j; k++) {        // 枚举切分点
                    int cost = dp[i][k] + dp[k + 1][j]
                             + maxLeaf[i][k] * maxLeaf[k + 1][j];
                    dp[i][j] = min(dp[i][j], cost);
                }
            }
        }
        return dp[0][n - 1];
    }
};
```

### Python

```python
class Solution:
    def mctFromLeafValues(self, arr: list[int]) -> int:
        n = len(arr)
        dp = [[0] * n for _ in range(n)]
        maxLeaf = [[0] * n for _ in range(n)]

        for i in range(n):
            maxLeaf[i][i] = arr[i]

        for length in range(2, n + 1):          # 区间长度
            for i in range(n - length + 1):     # 左端
                j = i + length - 1              # 右端
                maxLeaf[i][j] = max(maxLeaf[i][j - 1], arr[j])
                dp[i][j] = min(
                    dp[i][k] + dp[k + 1][j]
                    + maxLeaf[i][k] * maxLeaf[k + 1][j]
                    for k in range(i, j)        # 枚举切分点
                )
        return dp[0][n - 1]
```

> 💡 **实现细节**：① `maxLeaf[i][j]` 在主循环内顺手更新——利用 `max(maxLeaf[i][j-1], arr[j])`，$O(1)$ 继承左邻。② `dp[i][j]` 初值设 `INT_MAX`（C++），因为转移取 `min`；Python 用 `min(...)` 生成器表达式天然规避。③ 切分点 `k` 从 `i` 到 `j-1`，左子树 `[i..k]`、右子树 `[k+1..j]`，两段长度都严格小于 `len`，保证依赖已就绪。

## 4. 复杂度分析

| 维度 | 复杂度 | 说明 |
|------|--------|------|
| **时间** | $O(n^3)$ | 三重循环：区间长度 $O(n)$ × 左端 $O(n)$ × 枚举切分点 $O(n)$ |
| **空间** | $O(n^2)$ | 两张 $n \times n$ 表（`dp` + `maxLeaf`） |

> ⚠️ `n ≤ 40` 时 $n^3 = 64000$，远低于时间限制。与 [312](../0301-0400/312_戳气球.md)、[1039](../1001-1100/1039_多边形三角剖分的最低得分.md) 一样，区间 DP 的转移同时需要 `dp[i][k]` 和 `dp[k+1][j]` 两个方向，难以滚动降维，$O(n^2)$ 是此类问题的固有代价。

## 5. 扩展：单调栈 $O(n)$ 贪心解法

区间 DP 的 $O(n^3)$ 对 `n ≤ 40` 绰绰有余，但本题还有一个优雅的 $O(n)$ 解法。核心观察：

> **每对相邻叶值 $a \times b$ 最终都会作为某个非叶节点的值出现**——因为中序遍历固定，任意两个相邻叶子迟早会在某次合并中被直接组合。而**让较小的值尽早被消耗**（与它更小的邻居合并），就能让大值尽可能晚地参与乘法，从而最小化总和。

具体地，维护一个**单调递减栈**：

```python
class Solution:
    def mctFromLeafValues(self, arr: list[int]) -> int:
        stack = [float('inf')]      # 哨兵，保证栈底不空
        total = 0
        for val in arr:
            while stack[-1] <= val:            # 栈顶 ≤ 当前值，弹出
                mid = stack.pop()
                total += mid * min(stack[-1], val)
            stack.append(val)
        while len(stack) > 2:                  # 清理栈中剩余
            total += stack.pop() * stack[-1]
        return total
```

**直觉**：每当遇到一个比栈顶大的值 `val`，栈顶 `mid` 就是当前局部最小值——它必然要和左右邻居中较小的一个组合（代价 `mid × min(left, right)`），弹掉它就相当于「让小值尽早被消耗」。最终所有非叶节点的贡献之和即为答案。

| 维度 | 区间 DP | 单调栈 |
|------|---------|--------|
| **时间** | $O(n^3)$ | $O(n)$ |
| **空间** | $O(n^2)$ | $O(n)$ |
| **思路** | 枚举所有切分点求全局最优 | 贪心：小值尽早消耗 |
| **适用范围** | 通用区间 DP 模板 | 仅本题特定结构 |

> 💡 **面试推荐**：先讲区间 DP（通用模板、易于自圆其说），再点出单调栈 $O(n)$ 解法展示思维深度。两者答案一致，但单调栈的正确性证明较难，面试中作为「更优解」讨论即可。

## 6. 面试要点

1. **`dp[i][j]` 的定义是什么？为什么需要 `maxLeaf` 辅助表？**

   > `dp[i][j]` = 对叶子数组 `arr[i..j]` 构建二叉树时非叶节点的最小总和。根节点的值 = 左子树最大叶 × 右子树最大叶，而「子树最大叶」由区间本身决定（与子树结构无关），所以预计算 `maxLeaf[i][j]` 后，转移时 $O(1)$ 取值，无需在转移时重新扫描区间。

2. **为什么切分点 $k$ 枚举 `i` 到 `j-1`？**

   > 根的左子树叶子是 `arr[i..k]`，右子树叶子是 `arr[k+1..j]`。$k$ 从 $i$ 到 $j-1$ 覆盖所有合法切分——左子树至少 1 个叶子（$k \ge i$），右子树也至少 1 个叶子（$k \le j-1$）。每种切分对应一种树形，取最小代价。

3. **为什么按区间长度递增填表？**

   > `dp[i][j]` 依赖更短的子区间 `[i..k]`（长 $k-i+1 < \text{len}$）和 `[k+1..j]`（长 $j-k < \text{len}$）。按长度从小到大填充，保证计算当前状态时依赖已全部就绪——这是区间 DP 的通用遍历范式（同 [312](../0301-0400/312_戳气球.md)、[877](../0801-0900/877_石子游戏.md)）。

4. **与 [312. 戳气球](../0301-0400/312_戳气球.md) 有何异同？**

   > **同**：都是区间 DP，都枚举中间切分点 $k$，都按区间长度递增填表。**异**：312 求最大、开区间、代价是三元素乘积 $\text{val}[i]\text{val}[k]\text{val}[j]$（两端固定）；本题求最小、闭区间、代价是两区间属性之积 $\text{maxLeaf}[i][k] \times \text{maxLeaf}[k+1][j]$（需辅助表）。

5. **单调栈 $O(n)$ 解法的核心思想是什么？**

   > 每对相邻叶值迟早会被直接组合成某个非叶节点。让较小的值尽早与它更小的邻居合并（代价小），大值就尽可能晚地参与乘法。用单调递减栈，遇到比栈顶大的值时弹出栈顶（局部最小值），累加 `mid × min(left_neighbor, current_val)` 作为该次合并的代价。

> 💡 **一句话总结**：1130 是区间 DP 的招牌题——`dp[i][j]` 表示 `arr[i..j]` 构树的非叶节点最小和，枚举根切分点 $k$，转移 `dp[i][k] + dp[k+1][j] + maxLeaf[i][k] × maxLeaf[k+1][j]`，$O(n^3)$ 时间 $O(n^2)$ 空间。与 312 戳气球、1039 多边形剖分同属区间 DP 家族，掌握一题即可迁移一片。
