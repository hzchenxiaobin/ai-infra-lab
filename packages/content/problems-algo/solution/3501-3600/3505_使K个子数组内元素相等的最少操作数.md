# LeetCode 使K个子数组内元素相等的最少操作数 题解

- **关联**：3422（k=1 单窗口版）、3473（k 段划分 DP 骨架）、480（滑动中位数骨架）

## 1. 题目概述

- **标题 / 题号**：使 K 个子数组内元素相等的最少操作数（#3505，hard）
- **链接**：https://leetcode.cn/problems/minimum-operations-to-make-elements-within-k-subarrays-equal/
- **难度**：困难
- **标签**：数组、哈希表、数学、动态规划、滑动窗口、堆（优先队列）

**题意**：给定整数数组 `nums` 和两个整数 `x`、`k`。你可以执行以下操作任意次（包括零次）：将 `nums` 中的任意一个元素加 1 或减 1。返回使 `nums` 中**至少**包含 `k` 个长度**恰好**为 `x` 的**不重叠**子数组（每个子数组中的所有元素都相等）所需的最少操作数。子数组是数组中连续、非空的一段元素。

**示例 1**：

```text
输入：nums = [5,-2,1,3,7,3,6,4,-1], x = 3, k = 2
输出：8
解释：把下标 1..3 磨成 [1,1,1]（−2 加 3、3 减 2，共 5 次）；
      把下标 5..7 磨成 [4,4,4]（3 加 1、6 减 2，共 3 次）。总代价 5 + 3 = 8。
```

**示例 2**：

```text
输入：nums = [9,-2,-2,-2,1,5], x = 2, k = 2
输出：3
解释：把 nums[4] 减 3，数组变为 [9,-2,-2,-2,-2,5]，
      子数组 [−2,−2]（下标 1..2）与 [−2,−2]（下标 3..4）均全等，总代价 3。
```

**约束**：

- $2 \le n = \text{nums.length} \le 10^5$
- $-10^6 \le \text{nums[i]} \le 10^6$
- $2 \le x \le n$
- $1 \le k \le 15$
- $2 \le k \cdot x \le n$

> 💡 **读题关键**：① 选中窗口外的元素**碰都不用碰**——只要求「至少 k 个」合格窗口，多出来的元素无关紧要；② 单看一个窗口，「±1 凑齐到同一值」是 [462. 最小操作次数使数组元素相等 II](../0401-0500/462_最小操作次数使数组元素相等II.md) 的裸题，最优目标是**中位数**；③ 相邻定长窗口只差「一进一出」，滑动中位数可 $O(\log x)$ 增量维护——这正是 [3422](../3401-3500/3422_将子数组元素变为相等所需的最小操作数.md) 的全部内容；④ 「选 k 个不重叠定长窗口」是 [3473](../3401-3500/3473_长度至少为M的K个子数组之和.md) 的划分 DP 骨架，且**定长**让转移做到 $O(1)$。本题 = 3422 的代价预处理 + 3473 的选段 DP。

## 2. 解题思路

### 2.1 暴力思路

三重障碍叠加：

1. **枚举窗口位置**：从 $n - x + 1$ 个起点里组合枚举 $k$ 个互不重叠的窗口，组合数 $\binom{n-x+1}{k}$ 在 $n = 10^5$、$k = 15$ 下是天文数字；
2. **逐窗口算代价**：每个窗口独立「排序 → 取中位数 → 求绝对值和」要 $O(x \log x)$，全部窗口共 $O(n \cdot x \log x)$，上界约 $8.5 \times 10^{10}$；
3. **窗口间有依赖**：不是独立取 $k$ 个最小代价就能拼起来——**代价最小的窗口可能互相重叠**（示例 2 里代价为 0 的两个窗口 `[-2,-2]`（起点 1、2）就叠在一起，被迫选起点 1 与 3）。

暴力唯一的价值是点破正确性要素：**单窗口代价 = 中位数代价**、**总答案 = 在不重叠约束下选 k 个窗口求最小总代价**。前者用滑动窗口增量维护，后者用划分型 DP。

### 2.2 核心观察：两阶段流水线 = 滑动中位数 + 划分 DP

![核心观察：先逐窗算代价 cost[]，再用划分 DP 选 k 个不重叠窗口](../images/p3505_two_stage_concept.svg)

**观察一（单窗口最优目标是中位数）**：固定窗口，代价 $\text{cost}(t) = \sum_x |x - t|$ 是关于 $t$ 的分段线性**凸函数**，$t$ 处斜率为「小于 $t$ 的元素数 − 大于 $t$ 的元素数」，最小值在中位数处取得；窗口长度为偶数时两个中位数之间任何整数代价相同。

**观察二（相邻窗口一进一出 ⇒ 双有序集合）**：窗口右移一格，元素集合只发生「删一个旧、加一个新的」。用 $lo$（较小一半）与 $hi$（较大一半）两个多重有序集合 + 各自元素和 $s_{lo}$、$s_{hi}$，中位数 $m = \min(hi)$，则每个起点的代价 $O(1)$ 结算：

$$\text{cost}[i] = \big(s_{hi} - m \cdot |hi|\big) + \big(m \cdot |lo| - s_{lo}\big)$$

一趟扫描得到全部 $n - x + 1$ 个窗口代价，单步 $O(\log x)$——与 3422 / 480 完全同款，只是把「取全局 min」改成「存进 `cost[]` 表」。

**观察三（选 k 个不重叠窗口 = 划分 DP）**：定义

$$dp[j][i] = \text{前 } i \text{ 个元素中选出 } j \text{ 个长恰为 } x \text{ 的不重叠窗口的最小总代价}$$

按「第 $i$ 个元素是否被第 $j$ 个窗口覆盖」分类，转移只有两支：

$$dp[j][i] = \min\Big(dp[j][i-1],\ \ dp[j-1][i-x] + \text{cost}[i-x]\Big)$$

- **跳过**：$dp[j][i-1]$——窗口之间允许空隙（未覆盖的元素留着不动）；
- **收尾**：第 $j$ 个窗口恰好是起点 $i-x$ 的 $nums[i-x..i-1]$，它只与「前 $i-x$ 个元素里选好 $j-1$ 个窗口」拼接，**不重叠被编码进下标里**，无需额外校验。

因为窗口长度**恰为** $x$，收尾支的起点被钉死为 $t = i - x$——**唯一、无需枚举、无需任何前缀最值**（对比 3473 的「长度 ≥ m」还要用单变量 `best` 维护 $\max_t$）。边界 $dp[0][i] = 0$，答案 $dp[k][n]$；$k \cdot x \le n$ 保证可行，无需判无解。

### 2.3 算法流程图

![算法流程：阶段①双有序集合滑动求 cost[]，阶段②双层循环划分 DP，返回 dp[k][n]](../images/p3505_algorithm_flow.svg)

| 阶段 | 循环 | 关键动作 | 复杂度 |
|------|------|----------|--------|
| ① 滑动中位数 | $i = 0 \to n-1$ | 插入 → 上供 → 平衡 →（窗口成型时）结算 `cost[i-x+1]` → 移出 | $O(n \log x)$ |
| ② 划分 DP | $j = 1 \to k$，内层 $i = jx \to n$ | `ndp[i] = min(ndp[i-1], dp[i-x] + cost[i-x])`，一层结束 `swap(dp, ndp)` | $O(nk)$ |

阶段①的删除分支沿用 3422 的结论：值在哪个集合就删哪个（重复值跨集合时任删一份都不破坏 $\max(lo) \le \min(hi)$）；删除后的临时失衡不必立刻修，下一轮「插入 → 上供 → 平衡」自动纠正，而结算永远发生在平衡之后。

### 2.4 示例演算

用**示例 1**（`nums = [5,-2,1,3,7,3,6,4,-1]`，`x = 3`，`k = 2`）走一遍。

**阶段①：7 个窗口的代价表**（排序取中位数验证）：

| 起点$i$ | 窗口 | 排序后 | 中位数 $m$ | cost$[i]$ |
|---|---|---|---|---|
| 0 | `[5,−2,1]` | `[−2,1,5]` | 1 | $4+3+0 = 7$ |
| 1 | `[−2,1,3]` | `[−2,1,3]` | 1 | $3+0+2 = \mathbf{5}$ |
| 2 | `[1,3,7]` | `[1,3,7]` | 3 | $2+0+4 = 6$ |
| 3 | `[3,7,3]` | `[3,3,7]` | 3 | $0+4+0 = 4$ |
| 4 | `[7,3,6]` | `[3,6,7]` | 6 | $3+0+1 = 4$ |
| 5 | `[3,6,4]` | `[3,4,6]` | 4 | $1+2+0 = \mathbf{3}$ |
| 6 | `[6,4,−1]` | `[−1,4,6]` | 4 | $2+0+5 = 7$ |

**阶段②：划分 DP**（$dp$ 初值为全 0 的 $j=0$ 行）：

**第 1 层 $j = 1$**（收尾支 $= dp[i-3] + \text{cost}[i-3] = \text{cost}[i-3]$）：

| $i$ | 3 | 4 | 5 | 6 | 7 | 8 | 9 |
|---|---|---|---|---|---|---|---|
| $ndp[i]$ | 7 | 5 | 5 | 4 | 4 | 3 | 3 |

**第 2 层 $j = 2$**：

| $i$ | 收尾支 $dp[i-3]+\text{cost}[i-3]$ | $ndp[i] = \min(ndp[i-1],\ \text{收尾支})$ |
|---|---|---|
| 6 | $dp[3] + 4 = 11$ | 11 |
| 7 | $dp[4] + 4 = 9$ | 9 |
| 8 | $dp[5] + 3 = \mathbf{8}$ | **8** |
| 9 | $dp[6] + 7 = 11$ | 8 |

答案 $dp[2][9] = 8$：$j=1$ 层在 $i=5$ 处留下「前 5 个元素选 1 个窗口的最优 = 5（起点 1）」，$j=2$ 层在 $i=8$ 处接上起点 5 的窗口（代价 3）——正是官方解释中的 $[1,1,1]$ 与 $[4,4,4]$。

> 💡 注意 $i = 8$ 时收尾支用的是 $dp[5]$（不是 $dp[8-1]$ 所在的同层值）：**第 2 个窗口起点 5 之前必须已选好前 5 个元素中的 1 个窗口**，这正是「不重叠」在转移里的体现。

## 3. 参考代码

### C++

```cpp
class Solution {
  public:
    long long minOperations(vector<int>& nums, int x, int k) {
        int n = nums.size();
        vector<long long> cost(n - x + 1);
        multiset<long long> lo, hi;          // lo: 较小一半；hi: 较大一半，*hi.begin() 即中位数
        long long slo = 0, shi = 0;
        for (int i = 0; i < n; ++i) {
            lo.insert(nums[i]); slo += nums[i];        // ① 新元素先进 lo
            auto it = prev(lo.end());                   // ② lo 的最大值上供给 hi
            long long v = *it;
            lo.erase(it); slo -= v;
            hi.insert(v);  shi += v;
            if ((long long)hi.size() > (long long)lo.size() + 1) {  // ③ 平衡
                v = *hi.begin();
                hi.erase(hi.begin()); shi -= v;
                lo.insert(v); slo += v;
            }
            if (i >= x - 1) {                           // ④ 窗口成型，O(1) 结算
                long long m = *hi.begin();
                cost[i - x + 1] = (shi - m * (long long)hi.size())
                                + (m * (long long)lo.size() - slo);
                int out = nums[i - x + 1];              // ⑤ 移出滑出窗口的元素
                auto hit = hi.find(out);
                if (hit != hi.end()) { hi.erase(hit); shi -= out; }
                else { lo.erase(lo.find(out)); slo -= out; }
            }
        }
        vector<long long> dp(n + 1, 0), ndp(n + 1);     // 划分 DP：j = 0 行全 0
        for (int j = 1; j <= k; ++j) {
            for (int i = j * x; i <= n; ++i) {
                long long cur = dp[i - x] + cost[i - x];
                ndp[i] = (i == j * x) ? cur : min(ndp[i - 1], cur);
            }
            swap(dp, ndp);                              // 滚动到下一层
        }
        return dp[n];
    }
};
```

### Python

```python
from sortedcontainers import SortedList

class Solution:
    def minOperations(self, nums: List[int], x: int, k: int) -> int:
        n = len(nums)
        cost = [0] * (n - x + 1)                 # 阶段①：滑动中位数求每个窗口代价
        lo, hi = SortedList(), SortedList()      # lo: 较小一半；hi[0] 即中位数
        slo = shi = 0
        for i, v in enumerate(nums):
            lo.add(v); slo += v                  # ① 新元素先进 lo
            t = lo.pop()                         # ② lo 的最大值上供给 hi
            slo -= t; hi.add(t); shi += t
            if len(hi) > len(lo) + 1:            # ③ 平衡：|hi| - |lo| ∈ {0, 1}
                t = hi.pop(0)
                shi -= t; lo.add(t); slo += t
            if i >= x - 1:                       # ④ 窗口成型，O(1) 结算
                m = hi[0]
                cost[i - x + 1] = (shi - m * len(hi)) + (m * len(lo) - slo)
                out = nums[i - x + 1]            # ⑤ 移出滑出窗口的元素
                if out in hi:
                    hi.remove(out); shi -= out
                else:
                    lo.remove(out); slo -= out

        dp = [0] * (n + 1)                       # 阶段②：划分 DP，j = 0 行全 0
        for j in range(1, k + 1):
            ndp = [0] * (n + 1)
            for i in range(j * x, n + 1):
                cur = dp[i - x] + cost[i - x]
                ndp[i] = cur if i == j * x else min(ndp[i - 1], cur)
            dp = ndp                             # 滚动到下一层
        return dp[n]
```

> ⚠️ **三个易错点**：① `multiset` 删**单个**元素必须 `erase(iterator)`（先 `find`），`erase(value)` 会把等值元素全删；② DP 内层起点是 $j \cdot x$，且 $i = j \cdot x$ 时没有 $ndp[i-1]$ 可继承，必须直接取 `cur`——小下标的脏值永远读不到；③ 单窗口代价上界 $x \cdot 2 \times 10^6 = 2 \times 10^{11}$，$dp$ 上界再乘 $k$ 约 $3 \times 10^{12}$，必须 `long long`（Python 天然大数无碍）。

## 4. 复杂度分析

| 维度 | 复杂度 | 说明 |

| 时间复杂度 | $O(n \log n + nk)$ | 阶段①每个元素 $O(1)$ 次集合操作、单次 $O(\log x)$；阶段② $k$ 层 × 每层单趟 $O(n)$ |
| 空间复杂度 | $O(n)$ | `cost` 数组 + 两行滚动 `dp` + 双集合各存 $O(x)$ 个元素 |

## 5. 扩展：三道题的一张拼图

**（a）本题在三道旧题的交点上**：$k = 1$ 时阶段②退化为「取 $\min_i \text{cost}[i]$」，整题恰是 [3422](../3401-3500/3422_将子数组元素变为相等所需的最小操作数.md)；把「中位数代价」换成「区间和」，就是 [3473](../3401-3500/3473_长度至少为M的K个子数组之和.md) 的选段 DP；阶段①的数据结构正是 [480. 滑动窗口中位数](../0401-0500/480_滑动窗口中位数.md)。拼装题的通用套路：**先把「单段代价」做成可 $O(1)$ 查询的表，再套划分 DP**。

**（b）「长度恰好 x」是复杂度的命门**：定长带来两个唯一性——(i) 每个起点只有一个候选窗口，`cost[i]` 是单值，可滑动增量维护；(ii) DP 转移中最后一段起点 $t = i - x$ 唯一，连 3473 里那个维护前缀最值的 `best` 变量都省了。若改成「长度**至少** $x$」，(i) 直接失效：每个起点需对所有长度取中位数代价的最小值，代价表不再是单值，需要更重的手段（如逐右端点扫描 + 可删除结构），面试中能说清「为什么恰好定长才好做」即是加分项。

**（c）对顶堆 + 懒删除的等价实现**：Python 环境无 `sortedcontainers`（或 Java 无 `multiset`）时，$lo$ 用大根堆、$hi$ 用小根堆，删除走懒删除——哈希表记录「待删除值 → 个数」，堆顶弹出时若命中则跳过继续弹（对应官方标签里的「堆 / 哈希表」）。代价：删除变均摊 $O(\log x)$，双堆大小须按**有效元素数**计算，代码分支更多；两集合之和仍「真入堆时加、真弹出时减」。

## 6. 面试要点

1. **为什么单窗口的最优目标是中位数而不是平均值？**

   - $\text{cost}(t) = \sum |x - t|$ 是分段线性凸函数，$t$ 处斜率 =「左侧元素数 − 右侧元素数」，中位数左侧斜率为负、右侧为正，最小值恰在拐点取得；也可交换论证：目标两侧元素个数不等时向多的一侧移动 1，代价严格下降。平均值最小化的是平方和 $\sum (x-t)^2$，两问别混。

2. **滑动中位数的删除分支为什么安全？失衡要不要立刻修？**

   - 同一值可能同时出现在 $lo$ 和 $hi$，删哪一份都不破坏 $\max(lo) \le \min(hi)$，故「值在 $hi$ 就删 $hi$、否则删 $lo$」；删除后 $\lvert hi\rvert - \lvert lo\rvert$ 可能暂时越界到 $-1$ 或 $2$，但下一轮「插入 → 上供 → 平衡」自动纠正，而代价结算只发生在平衡之后，用到的划分永远合法。

3. **「不重叠」是怎么被编码进 DP 的？跳过分支为什么必不可少？**

   - 收尾支读的是 $dp[j-1][i-x]$：第 $j$ 个窗口起点 $i-x$，此前只允许在前 $i-x$ 个元素里选窗口，天然隔开至少 $x$ 个位置；跳过支 $dp[j][i-1]$ 允许窗口之间留空隙（窗口外的元素一个都不用改），缺了它就只能选「紧贴着排」的方案，会漏掉最优解。

4. **和 3473 相比为什么这题连 `best` 都不用维护？**

   - 3473 的段长是「≥ m」，最后一段起点 $t$ 是一个区间，需要把 $P[i]$ 提出 $\max$ 外、再用单变量维护 $\max_t (dp[j-1][t] - P[t])$；本题段长**恰为** $x$，$t = i-x$ 唯一，转移天然 $O(1)$。可见「定长/变长」直接决定划分 DP 有没有内层枚举。

5. **复杂度与数值边界卡在哪？**

   - 时间 $O(n \log n + nk)$，$k \le 15$ 是刻意的：DP 维被压到 $1.5 \times 10^6$，而 $k$ 若与 $n$ 同阶（如 3473 的 $k \le n/m$）就必须继续优化；数值上单窗代价 $\le x \cdot 2 \times 10^6 \approx 2 \times 10^{11}$、$dp \le 3 \times 10^{12}$，32 位整数必爆，C++ 全程 `long long`。
