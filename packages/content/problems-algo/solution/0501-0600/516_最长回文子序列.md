# LeetCode 最长回文子序列 题解

## 1. 题目概述

- **标题 / 题号**：最长回文子序列（#516，medium）
- **链接**：https://leetcode.cn/problems/longest-palindromic-subsequence/
- **难度**：中等
- **标签**：动态规划、区间 DP、字符串

**题意**：给你一个字符串 `s`，找出其中**最长的回文子序列**的长度。

**子序列**：从一个字符串中删除某些（也可不删）字符而不改变剩余字符相对顺序得到的新字符串。**回文**：正读反读相同，如 `"bbbab"` 中 `"bbbb"` 是回文子序列（删除第 4 个字符 `a`）。

**示例 1**：

```text
输入：s = "bbbab"
输出：4
解释：最长回文子序列是 "bbbb"，长度为 4。
```

**示例 2**：

```text
输入：s = "cbbd"
输出：2
解释：最长回文子序列是 "bb"，长度为 2。
```

**约束**：

- `1 <= s.length <= 1000`
- `s` 仅由小写英文字母组成

> 💡 这是**区间 DP 的经典模板**。与 [5. 最长回文子串](../0001-0100/5_最长回文子串.md) 求「连续」回文（中心扩展）不同，本题求「不连续」的回文**子序列**，需要让两端字符可以跳过中间任意字符配对——这正是区间 DP 擅长的场景。掌握 `dp[i][j] = s[i..j]` 这一区间定义后，可迁移到戳气球（312）、合并石头（1000）、奇怪的打印机（664）等一整类区间 DP 问题。

## 2. 解题思路

### 2.1 暴力思路：递归枚举两端

对子串 `s[i..j]`：若两端字符相同，则它们都可纳入回文，递归求解内部 `s[i+1..j-1]` 并 `+2`；若不同，则两端至少有一个不在回文中，分别尝试舍弃左端或右端，取较大值。时间 $O(2^n)$，指数级超时，且有大量重复子问题（同一个区间被反复求解）。

### 2.2 核心观察：区间 DP

![核心观察：dp[i][j] 表示 s[i..j] 的最长回文子序列长度，按区间长度递推](../images/lps_interval_dp_concept.svg)

**定义**：`dp[i][j]` = 子串 `s[i..j]`（闭区间）的最长回文子序列长度。

**边界**：

```text
dp[i][i] = 1                 # 单字符本身就是长度为 1 的回文
dp[i][i-1] = 0               # 空串（i > j）视为 0，处理长度 2 的配对
```

**转移**（核心）：

```text
若 s[i] == s[j]：
    dp[i][j] = dp[i+1][j-1] + 2        # 两端配对，回文向内缩 +2

若 s[i] != s[j]：
    dp[i][j] = max(dp[i+1][j],          # 舍弃左端 s[i]
                   dp[i][j-1])           # 舍弃右端 s[j]
```

**两种转移的直觉**：

| 情况 | DP 来源 | 含义 |
|------|---------|------|
| **两端字符相同** | `dp[i+1][j-1] + 2` | `s[i]` 与 `s[j]` 配对作回文首尾，内部取最长，总长 `+2` |
| **两端字符不同** | `max(dp[i+1][j], dp[i][j-1])` | `s[i]`、`s[j]` 不可能同时作首尾，分别舍弃一端取较大 |

> 💡 **为什么两端相同时直接 `dp[i+1][j-1]+2` 而不取 `max`？** 因为配对两端至少不比舍弃一端差：`dp[i+1][j-1]+2` 恒 $\geq$ `max(dp[i+1][j], dp[i][j-1])`。直觉：内部最长回文 `dp[i+1][j-1]` 可以原样保留，再把两个相同字符接到首尾，必然仍是回文，长度 `+2`。

> ⚠️ **区间 DP 的依赖方向**：`dp[i][j]` 依赖更短的区间——内层 `dp[i+1][j-1]`（长度 −2）、左缩 `dp[i+1][j]`（长度 −1）、右缩 `dp[i][j-1]`（长度 −1）。因此必须**按区间长度从短到长**填表（或让 `i` 从右往左、`j` 从左往右），保证算大区间时小区间已就绪。

**答案**：`dp[0][n-1]`（整个串的最长回文子序列）。

### 2.3 算法流程图

![算法流程：初始化边界 → i 从右往左、j 从左往右填表 → 返回 dp[0][n-1]](../images/lps_algorithm_flow.svg)

**完整步骤**：

1. **初始化**：`dp` 为 `n × n` 矩阵，全 0；令 `dp[i][i] = 1`（单字符边界）
2. **按依赖顺序填表**：`i` 从 `n-1` 到 `0`（自下而上），`j` 从 `i+1` 到 `n-1`（自左而右）：
   - `s[i] == s[j]` → `dp[i][j] = dp[i+1][j-1] + 2`
   - `s[i] != s[j]` → `dp[i][j] = max(dp[i+1][j], dp[i][j-1])`
3. **返回** `dp[0][n-1]`

> ⚠️ **为什么 `i` 倒序、`j` 正序？** `dp[i][j]` 依赖「下一行」`dp[i+1][...]` 和「同行左边」`dp[i][j-1]`。`i` 倒序保证 `i+1` 行已算完；`j` 正序保证 `j-1` 列已算完。`dp[i+1][j-1]` 同属下一行更靠左，也早已就绪。这就是区间 DP 经典的填表顺序。

### 2.4 示例演算

以 `s = "bbbab"` 为例：

![示例演算：bbbab 的区间 DP 填表，答案 dp[0][4]=4](../images/lps_example_walkthrough.svg)

**dp 表**（行 = `i`，列 = `j`，仅填上三角 `i <= j`；`i > j` 为空串 = 0）：

| | `j=0` (b) | `j=1` (b) | `j=2` (b) | `j=3` (a) | `j=4` (b) |
|------|-----------|-----------|-----------|-----------|-----------|
| `i=0` (b) | 1 | 2 | **3** | 3 | **4** |
| `i=1` (b) | — | 1 | 2 | 2 | 3 |
| `i=2` (b) | — | — | 1 | 1 | 3 |
| `i=3` (a) | — | — | — | 1 | 1 |
| `i=4` (b) | — | — | — | — | 1 |

**关键填表步骤**：

| 格子 | 字符比较 | 转移 | 值 | 说明 |
|------|----------|------|----|------|
| `dp[0][1]` | `b` == `b` | `dp[1][0]+2` | 2 | 两 b 配对，回文 `"bb"` |
| `dp[0][2]` | `b` == `b` | `dp[1][1]+2` | 3 | 首尾 b 配对，内部 `"b"`，得 `"bbb"` |
| `dp[2][3]` | `b` ≠ `a` | `max(dp[3][3], dp[2][2])` | 1 | 舍弃一端，仅剩单字符 |
| `dp[0][4]` | `b` == `b` | `dp[1][3]+2` | 4 | 首尾 b 配对，内部 `"bb"`，得 `"bbbb"` ✓ |

最终 `dp[0][4] = 4`，最长回文子序列为 `"bbbb"`（删除下标 3 的 `a`）。

> 💡 **如何还原回文串？** 从 `dp[0][n-1]` 回溯：若 `s[i]==s[j]` 且 `dp[i][j]==dp[i+1][j-1]+2`，则 `s[i]`、`s[j]` 在回文首尾，分别记录并走向 `[i+1][j-1]`；否则走向 `dp[i+1][j]` 或 `dp[i][j-1]` 中较大者。最终把首尾记录的字符正序拼接、中间内部回文夹在中间即可。

## 3. 参考代码

### C++

```cpp
// 最长回文子序列.cpp —— 区间 DP
// 编译: g++ -O2 -std=c++17 最长回文子序列.cpp -o lps
class Solution {
public:
    int longestPalindromeSubseq(string s) {
        int n = s.size();
        vector<vector<int>> dp(n, vector<int>(n, 0));
        for (int i = 0; i < n; i++) dp[i][i] = 1;          // 单字符边界

        for (int i = n - 1; i >= 0; i--) {                 // i 自下而上
            for (int j = i + 1; j < n; j++) {              // j 自左而右
                if (s[i] == s[j]) {
                    dp[i][j] = dp[i + 1][j - 1] + 2;       // 两端配对 +2
                } else {
                    dp[i][j] = max(dp[i + 1][j], dp[i][j - 1]); // 舍弃一端
                }
            }
        }
        return dp[0][n - 1];
    }
};
```

### Python

```python
class Solution:
    def longestPalindromeSubseq(self, s: str) -> int:
        n = len(s)
        dp = [[0] * n for _ in range(n)]
        for i in range(n):
            dp[i][i] = 1                                # 单字符边界

        for i in range(n - 1, -1, -1):                  # i 自下而上
            for j in range(i + 1, n):                   # j 自左而右
                if s[i] == s[j]:
                    dp[i][j] = dp[i + 1][j - 1] + 2     # 两端配对 +2
                else:
                    dp[i][j] = max(dp[i + 1][j], dp[i][j - 1])  # 舍弃一端

        return dp[0][n - 1]
```

> 💡 **实现细节**：① `dp` 为 `n × n`，`i > j` 的下三角保持 0（即空串），这样 `j = i+1` 时 `dp[i+1][j-1] = dp[i+1][i] = 0`，长度为 2 的相同字符对自动得到 `0 + 2 = 2`，无需特判。② `i` 倒序、`j` 正序是关键，保证依赖的更短区间已算完。③ `dp[i][i] = 1` 也可并入外层循环（每次先置 `dp[i][i]=1` 再走内层 `j`）。

## 4. 复杂度分析

| 维度 | 区间 DP | 滚动数组 |
|------|---------|---------|
| **时间** | `O(n²)` | `O(n²)` |
| **空间** | `O(n²)` | `O(n)` |
| **能否还原回文串** | ✓ 回溯 dp 表 | ✗ 只得长度 |

> ⚠️ 时间 `O(n²)`：双重循环填满约 `n²/2` 个上三角格子，每格 `O(1)` 转移。`n ≤ 1000` 时约 $5 \times 10^5$ 次操作，远低于时限。

## 5. 扩展：转化为最长公共子序列

一个优雅的等价视角：**字符串 `s` 的最长回文子序列 = `s` 与其反转 `rev(s)` 的最长公共子序列（LCS）**。

> 💡 **直觉**：回文正读反读相同，所以一个回文子序列必然同时出现在 `s` 和 `rev(s)` 中；反之 `s` 与 `rev(s)` 的任何公共子序列都可配成一个回文（取对称位置）。因此两者长度相等。

```python
class Solution:
    def longestPalindromeSubseq(self, s: str) -> int:
        t = s[::-1]
        n = len(s)
        dp = [[0] * (n + 1) for _ in range(n + 1)]
        for i in range(1, n + 1):
            for j in range(1, n + 1):
                if s[i - 1] == t[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1] + 1
                else:
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
        return dp[n][n]
```

这是 [1143. 最长公共子序列](../1101-1200/1143_最长公共子序列.md) 的直接套用，时间同为 `O(n²)`。两种解法等价，但**区间 DP 视角更直观地揭示了「回文」结构**，也是面试官期望看到的主解法；LCS 转化则适合作为加分思路或快速复用模板。

### 空间优化：滚动数组

区间 DP 同样可压缩到 `O(n)`：`dp[i][j]` 只依赖下一行 `dp[i+1][...]`，用一维数组滚动即可。但 `dp[i+1][j-1]`（左下角）会被左方 `dp[i][j-1]` 的更新覆盖，需用变量暂存「上一行同列旧值」。

```python
class Solution:
    def longestPalindromeSubseq(self, s: str) -> int:
        n = len(s)
        dp = [0] * n
        for i in range(n - 1, -1, -1):
            dp[i] = 1                       # dp[i][i] = 1
            prev = 0                        # dp[i+1][i] = 0（左下角，初始为空串）
            for j in range(i + 1, n):
                temp = dp[j]                # 暂存 dp[i+1][j]（下一行旧值）
                if s[i] == s[j]:
                    dp[j] = prev + 2        # dp[i+1][j-1] + 2
                else:
                    dp[j] = max(dp[j], dp[j - 1])  # max(dp[i+1][j], dp[i][j-1])
                prev = temp                 # 滚动为下一轮的左下角
        return dp[n - 1]
```

> 💡 **prev 的作用**：`dp[j]` 计算前保存的是上一行的 `dp[i+1][j]`，计算后 `dp[j]` 变成当前行 `dp[i][j]`，而 `dp[j-1]` 已是当前行。`prev` 在覆盖前留住旧值，下一轮 `j+1` 时它正好充当 `dp[i+1][j]`（即新左下角 `dp[i+1][(j+1)-1]`）。

## 6. 面试要点

1. **`dp[i][j]` 的定义是什么？为什么用闭区间 `s[i..j]`？**

   > `dp[i][j]` = 子串 `s[i..j]`（闭区间）的最长回文子序列长度。用闭区间是因为回文「首尾配对」天然对应区间两端 `s[i]`、`s[j]`，转移时两端向内缩到 `s[i+1..j-1]`，闭区间表达最自然。答案即 `dp[0][n-1]`。

2. **为什么必须按区间长度递推，而不能像普通二维 DP 那样逐行填？**

   > 区间 DP 中 `dp[i][j]` 依赖**更短的区间**（长度 −1 或 −2），而非「左上方的同行/同列」。若按 `i` 正序逐行填，算 `dp[i][j]` 时 `dp[i+1][...]`（下一行）尚未计算。正确做法是 `i` 倒序、`j` 正序，保证「下一行」和「同行左方」都已就绪——本质仍是按长度从短到长。

3. **两端字符不同时为什么取 `max(dp[i+1][j], dp[i][j-1])` 而非 `dp[i+1][j-1]`？**

   > `s[i] != s[j]` 意味着两者不可能同时作回文首尾，至少一个要被舍弃。`dp[i+1][j]` = 舍弃 `s[i]`，`dp[i][j-1]` = 舍弃 `s[j]`，取较大。不取 `dp[i+1][j-1]`（两者都舍弃）是因为它 $\leq$ 前两者（舍弃一个的子问题已包含舍弃两个的情形）。

4. **长度为 2 的相同字符对（如 `"bb"`）如何处理？需要特判吗？**

   > 无需特判。`dp` 初始化为 0，`i > j` 的下三角恒为 0（代表空串）。当 `j = i+1` 且 `s[i]==s[j]` 时，`dp[i+1][j-1] = dp[i+1][i] = 0`，于是 `dp[i][j] = 0 + 2 = 2`，正好是两个相同字符组成的回文长度。把空串视为 0 让转移式统一成立。

5. **本题与「最长回文子串」（5）有何区别？**

   > 子**串**必须连续，子**序列**可以不连续。求子串用「中心扩展」或 Manacher，以每个位置为中心向两边扩散，不匹配即中断；求子序列用区间 DP，两端不匹配时不必中断，而是 `max(舍弃左端, 舍弃右端)` 跳过中间字符。两者 DP 转移也不同：子串版 `dp[i][j]` 表示「是否为回文」，子序列版表示「最长长度」。

> 💡 **一句话总结**：516 是区间 DP 的经典模板——`dp[i][j]` 表示 `s[i..j]` 的最长回文子序列，两端相同则 `dp[i+1][j-1]+2`，不同则 `max(左缩, 右缩)`，按 `i` 倒序、`j` 正序填表。`O(n²)` 时间，可滚动到 `O(n)` 空间。等价于 `s` 与 `rev(s)` 的 LCS。这个「两端配对向内缩」的区间 DP 模板可迁移到戳气球、合并石头、奇怪的打印机等一整类问题，是面试必会的核心套路。
