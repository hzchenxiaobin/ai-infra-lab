# LeetCode 两个子序列的最大点积 题解

## 1. 题目概述

- **标题 / 题号**：两个子序列的最大点积（#1458，medium）
- **链接**：https://leetcode.cn/problems/maximum-dot-product-of-two-subsequences/
- **难度**：中等
- **标签**：动态规划、二维 DP、数组

**题意**：给定两个数组 `nums1` 和 `nums2`，从 `nums1` 中选一个**非空子序列**，从 `nums2` 中选一个**非空子序列**（两者长度相同），使它们的**点积最大**。返回该最大点积。

**子序列**：从原数组中删除若干（也可不删）元素而不改变剩余元素相对顺序得到的新数组。

**点积**：长度相同的两个数组 `a`、`b` 的点积为 $\sum_{k} a[k] \times b[k]$。

**示例 1**：

```text
输入：nums1 = [2,1,-2,5], nums2 = [3,0,-6]
输出：18
解释：选子序列 [2,-2]（来自 nums1）和 [3,-6]（来自 nums2），
      点积 = 2×3 + (-2)×(-6) = 6 + 12 = 18。
```

**示例 2**：

```text
输入：nums1 = [3,-2], nums2 = [2,-6,7]
输出：21
解释：选子序列 [3]（来自 nums1）和 [7]（来自 nums2），
      点积 = 3×7 = 21。
```

**示例 3**：

```text
输入：nums1 = [-1,-1], nums2 = [1,1]
输出：-1
解释：所有元素乘积均为负，只能选一对使损失最小：(-1)×1 = -1。
```

**约束**：

- `1 <= nums1.length, nums2.length <= 500`
- `-1000 <= nums1[i], nums2[i] <= 1000`

> 💡 本题是 [1143. 最长公共子序列](../1101-1200/1143_最长公共子序列.md) 的**同构变体**——同样是「两序列逐位置交互」的二维 DP，只是把「匹配时长度 `+1`」换成了「配对时累加乘积 `nums1[i]×nums2[j]`」，目标从「求最长」变成「求最大和」。多了一个**负数陷阱**：当前缀最优值为负时，宁可抛弃前缀只取当前这一对，于是状态转移里要同时比较「单独配对」与「配对 + 前缀」。

## 2. 解题思路

### 2.1 暴力思路：枚举所有子序列对

从 `nums1` 的 $2^m - 1$ 个非空子序列中选一个，从 `nums2` 的 $2^n - 1$ 个非空子序列中选一个，长度相同才计算点积。时间 $O(2^{m+n})$，指数级爆炸。

### 2.2 核心观察：二维 DP

![核心观察：dp[i][j] = nums1 前 i 个与 nums2 前 j 个的最大点积](../images/1458_dp_transition.svg)

**定义**：`dp[i][j]` = 从 `nums1[0..i-1]` 与 `nums2[0..j-1]` 中各选一个**等长非空子序列**所能得到的最大点积。

**边界**：

```text
dp[0][j] = -∞      # nums1 为空，无法构成非空子序列
dp[i][0] = -∞      # nums2 为空，无法构成非空子序列
```

> ⚠️ 边界初始化为 $-\infty$ 而非 `0`，是本题的关键。若初始化为 `0`，全负数样例（示例 3）会错误返回 `0`——因为「不选任何元素」的空点积 `0` 会被误当作合法答案。$-\infty$ 表示「不可达」，强制至少配一对。

**转移**（核心）：令 $p = \text{nums1}[i{-}1] \times \text{nums2}[j{-}1]$，对每个 $(i, j)$ 有四种选择：

```text
① 单独配对：           p                        # 只要这一对，抛弃所有前缀
② 配对 + 续接前缀：     p + dp[i-1][j-1]         # 当前对拼在之前最优序列末尾
③ 跳过 nums1[i-1]：     dp[i-1][j]               # nums1[i-1] 不参与配对
④ 跳过 nums2[j-1]：     dp[i][j-1]               # nums2[j-1] 不参与配对

dp[i][j] = max(①, ②, ③, ④)
```

**四种转移的直觉**：

| 选项 | 来源 | 含义 |
|------|------|------|
| **① 单独配对** | $p$ | 只取 `nums1[i-1]` 与 `nums2[j-1]` 这一对，前缀太差（为负）则丢弃 |
| **② 配对+前缀** | $p + \text{dp}[i{-}1][j{-}1]$ | 当前对续接到前缀最优序列后面，前缀为正时增益 |
| **③ 跳过 nums1[i-1]** | $\text{dp}[i{-}1][j]$ | `nums1[i-1]` 不配对，结果沿用更短的 `nums1` 前缀 |
| **④ 跳过 nums2[j-1]** | $\text{dp}[i][j{-}1]$ | `nums2[j-1]` 不配对，结果沿用更短的 `nums2` 前缀 |

> 💡 **为什么需要 ①「单独配对」？** 当 `dp[i-1][j-1] < 0`（前缀最优为负）时，`② = p + 负数 < p = ①`，续接前缀反而拉低点积。此时应抛弃前缀、只留当前这对。`max(①, ②)` 自动在「续接」与「单飞」间取优——这正是 LCS 里没有的负数陷阱。

**答案**：`dp[m][n]`。

> 💡 **与 LCS 的对比**：把「配对累加乘积」替换为「匹配长度 +1」，把「max」替换为相应方向的 max，结构几乎一致。LCS 中匹配时不需要「单飞」选项，因为长度恒非负、续接永不亏损；本题乘积可负，故多一个「抛弃前缀」的选择。

### 2.3 算法流程图

![算法流程：初始化 -∞ 边界 → 逐行填表四选一 → 返回 dp[m][n]](../images/1458_algorithm_flow.svg)

**完整步骤**：

1. **初始化**：`dp` 为 `(m+1) × (n+1)` 矩阵，第 0 行和第 0 列全填 $-\infty$（空数组不可达）
2. **逐行填表**：`i` 从 1 到 `m`，`j` 从 1 到 `n`：
   - 计算 $p = \text{nums1}[i{-}1] \times \text{nums2}[j{-}1]$
   - `dp[i][j] = max(p, p + dp[i-1][j-1], dp[i-1][j], dp[i][j-1])`
3. **返回** `dp[m][n]`

> ⚠️ **填表顺序**：从左到右、从上到下。`dp[i][j]` 依赖左上 (`dp[i-1][j-1]`)、正上 (`dp[i-1][j]`)、左方 (`dp[i][j-1]`)，三者都要先算出来。

### 2.4 示例演算

以 `nums1 = [2, 1, -2, 5]`, `nums2 = [3, 0, -6]` 为例：

![示例演算：填 dp 表，答案 dp[4][3]=18](../images/1458_example_walkthrough.svg)

**dp 表**（行 = nums1 元素，列 = nums2 元素，首行/首列为 $-\infty$ 边界，下表用 `−∞` 简记）：

| | `−∞` | `3` | `0` | `−6` |
|------|------|------|------|------|
| `−∞` | −∞ | −∞ | −∞ | −∞ |
| `2` | −∞ | **6** | 6 | 6 |
| `1` | −∞ | 6 | 6 | 6 |
| `−2` | −∞ | 6 | 6 | **18** |
| `5` | −∞ | 15 | 15 | **18** |

**关键填表步骤**：

| 格子 | 乘积 p | 四选一 | 值 | 说明 |
|------|--------|--------|----|------|
| `dp[1][1]` | 2×3=6 | max(6, 6+(−∞), −∞, −∞) | **6** | 首对，边界为 −∞ 只能①单飞 |
| `dp[1][3]` | 2×(−6)=−12 | max(−12, −12+(−∞), −∞, dp[1][2]=6) | **6** | ④跳过 −6，沿用 `[2]·[3]`=6 |
| `dp[3][3]` | (−2)×(−6)=12 | max(12, 12+dp[2][2]=18, dp[2][3]=6, dp[3][2]=6) | **18** | ②续接前缀 6 → 12+6=18 ✓ |
| `dp[4][3]` | 5×(−6)=−30 | max(−30, −30+dp[3][2]=−24, dp[3][3]=18, dp[4][2]=15) | **18** | ③跳过 5，沿用 dp[3][3]=18 |

> 💡 **关键一步 `dp[3][3]=18`**：负负得正，`(−2)×(−6)=12` 是个大正数，续接到前缀 `dp[2][2]=6`（即 `2×3`）上得 18，远优于单飞 12 或跳过。这正是「②配对+前缀」发光的场景——两个负数配对产生正增益。

> ⚠️ **易错点 `dp[1][3]`**：`2×(−6)=−12` 是负数，续接 (`−12+dp[1][2]` 中 `dp[1][2]` 来自 `dp[i-1][j-1]=dp[0][2]=−∞`) 不可达；但 ④ `dp[1][2]=6`（跳过 `−6`）更大，所以 `dp[1][3]=6` 而非 −12。负元素不一定拉低结果——只要能跳过它。

**最优解回溯**：`dp[4][3]=18` 来自 ③ `dp[3][3]`（跳过 `5`）；`dp[3][3]=18` 来自 ② `12 + dp[2][2]`；`dp[2][2]=6` 沿用 `dp[1][1]=6`（即 `2×3`）。所以选了 `nums1` 中的 `[2, −2]` 与 `nums2` 中的 `[3, −6]`，点积 $2\times3 + (−2)\times(−6) = 6 + 12 = 18$。

## 3. 参考代码

### C++

```cpp
// 两个子序列的最大点积.cpp —— 二维 DP
// 编译: g++ -O2 -std=c++17 两个子序列的最大点积.cpp -o maxdot
class Solution {
public:
    int maxDotProduct(vector<int>& nums1, vector<int>& nums2) {
        int m = nums1.size(), n = nums2.size();
        const int NEG_INF = INT_MIN / 2;                 // 防 -INF + p 溢出
        vector<vector<int>> dp(m + 1, vector<int>(n + 1, NEG_INF));

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                int p = nums1[i-1] * nums2[j-1];
                dp[i][j] = max({                         // 四选一
                    p,                                   // ① 单独配对
                    p + dp[i-1][j-1],                    // ② 配对 + 续接前缀
                    dp[i-1][j],                          // ③ 跳过 nums1[i-1]
                    dp[i][j-1]                           // ④ 跳过 nums2[j-1]
                });
            }
        }
        return dp[m][n];
    }
};
```

### Python

```python
class Solution:
    def maxDotProduct(self, nums1: List[int], nums2: List[int]) -> int:
        m, n = len(nums1), len(nums2)
        NEG_INF = float('-inf')
        dp = [[NEG_INF] * (n + 1) for _ in range(m + 1)]

        for i in range(1, m + 1):
            for j in range(1, n + 1):
                p = nums1[i-1] * nums2[j-1]
                dp[i][j] = max(
                    p,                          # ① 单独配对
                    p + dp[i-1][j-1],           # ② 配对 + 续接前缀
                    dp[i-1][j],                 # ③ 跳过 nums1[i-1]
                    dp[i][j-1]                  # ④ 跳过 nums2[j-1]
                )

        return dp[m][n]
```

> 💡 **实现细节**：① C++ 中用 `INT_MIN / 2` 而非 `INT_MIN` 作为 $-\infty$，避免 `p + dp[i-1][j-1]` 在 `dp` 为 `INT_MIN` 时溢出。② `max({...})` 的 initializer_list 写法一次比较四项，简洁且无额外开销。③ `dp[0][*]` 与 `dp[*][0]` 全为 $-\infty$，保证首个格子 `dp[1][1]` 只能取 `① = p`（其余三项为 $-\infty$ 或 $p + (-\infty)$），自然满足「非空」约束。

## 4. 复杂度分析

| 维度 | 二维 DP | 滚动数组 |
|------|---------|---------|
| **时间** | $O(m \times n)$ | $O(m \times n)$ |
| **空间** | $O(m \times n)$ | $O(n)$ |
| **依赖方向** | 左上 / 正上 / 左方 | 同左，需 prev 变量保左上 |

> ⚠️ 时间 $O(m \times n)$：双重循环遍历 $(m{+}1) \times (n{+}1)$ 个格子，每格 $O(1)$ 四选一。$m, n \leq 500$ 时约 $2.5 \times 10^5$ 次操作，可接受。

## 5. 扩展：滚动数组空间优化

`dp[i][j]` 只依赖上一行（`dp[i-1][j-1]`、`dp[i-1][j]`）和当前行左方（`dp[i][j-1]`），可用**一维数组 + prev 变量**压缩到 $O(n)$ 空间：

```python
class Solution:
    def maxDotProduct(self, nums1: List[int], nums2: List[int]) -> int:
        m, n = len(nums1), len(nums2)
        NEG_INF = float('-inf')
        dp = [NEG_INF] * (n + 1)                        # 第 0 行全 -∞

        for i in range(1, m + 1):
            prev = dp[0]                                # dp[i-1][0] = -∞
            for j in range(1, n + 1):
                temp = dp[j]                            # 保存 dp[i-1][j]
                p = nums1[i-1] * nums2[j-1]
                dp[j] = max(p, p + prev, dp[j], dp[j-1])
                prev = temp                             # 滚动 prev
        return dp[n]
```

> 💡 **prev 的作用**：`dp[j]` 计算需要左上角 `dp[i-1][j-1]`，但一维数组中 `dp[j-1]` 已被更新为当前行新值，左上角丢失。`prev` 在覆盖 `dp[j]` 前保存旧值（上一行的 `dp[j]`），下一次迭代 `j+1` 时作为 `dp[i-1][j]`（即新的左上角）使用。与 [1143. 最长公共子序列](../1101-1200/1143_最长公共子序列.md)、[72. 编辑距离](../0001-0100/72_编辑距离.md) 的滚动数组技巧完全一致。

## 6. 面试要点

1. **`dp[i][j]` 的定义是什么？边界为什么是 $-\infty$ 而非 `0`？**

   > `dp[i][j]` = 从 `nums1[0..i-1]` 与 `nums2[0..j-1]` 各选一个等长非空子序列的最大点积。边界 `dp[0][*] = dp[*][0] = -∞` 表示「空数组无法构成非空子序列，不可达」。若初始化为 `0`，全负样例会误返回 `0`（空点积），违反非空约束。

2. **为什么转移里要有「单独配对」这一项？**

   > 当 `dp[i-1][j-1] < 0`（前缀最优为负）时，`p + dp[i-1][j-1] < p`，续接前缀反而拉低点积。`max(p, p + dp[i-1][j-1])` 自动在「续接」与「单飞」间取优。LCS 里长度恒非负、续接永不亏损，所以不需要这一项——这是本题相对 LCS 的核心差异。

3. **本题与 LCS（1143）的转移结构有何异同？**

   > 同：都是两序列二维 DP，`dp[i][j]` 依赖左上、正上、左方三格，填表顺序一致，都可滚动数组压到 $O(n)$。异：LCS 匹配时 `dp[i-1][j-1]+1`，不匹配取 `max(上方, 左方)`；本题配对时 `max(p, p+dp[i-1][j-1])`（多了单飞），且不论是否「匹配」都要和 `max(上方, 左方)` 比较——因为任意位置都可选作配对终点。

4. **C++ 中为什么用 `INT_MIN / 2` 而非 `INT_MIN`？**

   > 转移式有 `p + dp[i-1][j-1]`，当 `dp[i-1][j-1] = INT_MIN` 且 `p > 0` 时会触发有符号整数溢出（UB）。取 `INT_MIN / 2 ≈ -10^9`，加上 `|p| ≤ 10^6` 后仍远不溢出，且作为「不可达哨兵」语义不变。

5. **能否用 `max(0, dp[i-1][j-1])` 简化转移？**

   > 可以写成 `dp[i][j] = max(dp[i-1][j], dp[i][j-1], p + max(0, dp[i-1][j-1]))`，但**只有当边界初始化为 `0` 时**才等价于「允许空序列」。然而边界为 `0` 会让全负样例错误返回 `0`。所以要么保持 $-\infty$ 边界 + 显式四选一，要么用 `0` 边界 + `max(0, ...)` 但需单独处理全负情形——前者更简洁不易错。

> 💡 **一句话总结**：1458 是二维 DP 的「带负数版 LCS」——`dp[i][j]` 表示两前缀的最大点积，配对时四选一 `max(p, p+dp[i-1][j-1], dp[i-1][j], dp[i][j-1])`，边界 $-\infty$ 保证非空。$O(m \times n)$ 时间，滚动数组可压到 $O(n)$ 空间。
